# 基于构型耦合时空风险占据与 NUBS 轨迹优化的机械臂动态安全运动生成论文框架

## 1. 论文总体定位

本文不建议将研究对象限定为“动态抓取”，而应将主任务定义为：

> 动态环境下机器人操作臂的感知驱动安全运动生成。

更具体地说，本文研究的问题是：

> 机器人操作臂在 RGB-D 相机感知到静态障碍和动态障碍后，如何利用当前构型下的 URDF/Mesh 本体表面点云构建全身时空风险，并以 NUBS minimum-control-effort 轨迹为连续表示，生成满足任务目标、机械约束、轨迹平滑性和动态安全性的可执行轨迹。

因此，本文的核心不是单纯做环境感知，也不是单纯使用 NUBS 进行轨迹规划，而是：

> 将环境感知得到的静态/动态障碍占据信息，与由 URDF/Mesh 和实时关节状态生成的机器人本体表面点云进行构型耦合，并将所得全身时空风险嵌入 NUBS 连续轨迹优化；在执行层采用风险触发的低频重规划与高频调速、排斥和急停保护，实现可分阶段落地的动态安全运动生成。

本文采用分阶段研究边界：

```text
现有基础：RGB-D 点云处理、URDF/Mesh 本体点云解耦、对象跟踪、短时预测、全身风险距离、速度级安全响应
论文主体：基于上述风险前端的离线/低频 NUBS 安全轨迹优化
在线扩展：风险触发的低频局部重规划，并由现有高频安全控制层兜底
```

因此，论文不把“全管线持续高频滚动优化”作为成立前提，而是先证明几何建模、风险映射和轨迹优化的有效性，再验证低频在线更新能力。

## 2. 推荐论文题目

### 中文题目

**基于构型耦合时空风险占据与非均匀 B 样条优化的机器人操作臂动态安全运动生成方法**

### 英文题目

**Configuration-Coupled Spatio-Temporal Risk Occupancy and Non-Uniform B-Spline Optimization for Safe Manipulator Motion in Dynamic Environments**

### 方法简称

建议使用：

**CCRO-NUBS**

即：

**Configuration-Coupled Risk Occupancy constrained Non-Uniform B-Spline trajectory optimization**

中文可译为：

**构型耦合风险占据约束非均匀 B 样条轨迹优化方法**

### 术语与能力边界

为保持题目和方法简称的辨识度，本文保留 CCRO-NUBS 中的“风险约束”表述，但在方法推导和实验分析中统一采用更准确的“风险代价驱动轨迹优化”。除非后续实现显式不等式约束并逐时刻验证

```text
D_min(q(t), t) >= d_safe
```

否则不宣称严格安全保证。同时，本文不宣称全局最优、高频完整滚动优化或对动态障碍未来运动的准确预测。NUBS 负责生成平滑的未来参考轨迹，高频速度级安全层负责优化未完成、失败或突发风险情况下的实时兜底。

## 3. 主任务定义

### 3.1 任务输入

系统输入包括：

```text
机械臂当前状态：
q0, qdot0, qddot0

目标状态：
q_goal

环境感知信息：
RGB-D 点云、静态障碍、动态障碍位置与速度

机械臂模型：
URDF、各连杆 Mesh、局部表面预采样点、关节位置/速度/加速度限制
```

其中：

- `q0` 为机械臂当前关节位置；
- `qdot0` 为当前关节速度；
- `qddot0` 为当前关节加速度；
- `q_goal` 为目标关节构型，作为第一版轨迹优化的明确终端条件；
- 环境感知信息用于构建静态和动态障碍风险场。

本文主体不直接优化任务空间目标。`x_goal` 仅作为扩展说明：在具备稳定逆运动学后，先将目标末端位姿转换为经过可达性和碰撞初检的 `q_goal`，再进入本文关节空间轨迹优化流程。

### 3.2 任务输出

系统输出为连续时间关节轨迹：

```text
q(t), t ∈ [0, T]
```

论文主体的标准任务固定为：

```text
输入：q_start, q_goal, 当前/预测障碍序列 O(t), URDF/Mesh 机器人模型
输出：连续关节轨迹 q(t), t in [0, T]
```

该轨迹需要满足：

```text
1. 机械臂到达目标关节构型 q_goal；
2. 机械臂本体各连杆避开静态障碍；
3. 机械臂本体各连杆避开动态障碍未来占据区域；
4. 关节位置、速度、加速度不超限；
5. 轨迹平滑、连续、可执行；
6. 在规划层支持风险触发的低频轨迹更新；
7. 在执行层保留高频调速、排斥和急停安全保护。
```

### 3.3 任务成功条件

一次轨迹规划或闭环试验只有同时满足以下条件，才记为成功：

```text
目标到达：||q(T) - q_goal|| <= epsilon_goal
安全要求：D_min(q(t), t) >= d_stop，且报告低于 d_safe 的累计时间
运动学要求：q、qdot、qddot 均不超过给定关节限制
执行要求：规划未超时，候选轨迹通过高密度 Mesh 复核
```

其中 `d_stop` 用于判定危险侵入，`d_safe` 用于风险代价和安全裕度评价。本文分别报告目标误差、安全距离、运动学违反和求解状态，避免仅凭“未碰撞”判定任务成功。

### 3.4 最终目标效果

本文希望实现的效果是：

> 机械臂能够根据动态环境感知结果构建未来短时间窗口内的保守风险分布，并主动调整自身全身构型轨迹，使机械臂在到达目标关节构型 `q_goal` 的同时，各连杆保持安全距离，轨迹满足运动学约束和平滑性要求。

## 4. 应用意义

本文方法具有以下应用意义：

### 4.1 动态环境下的机械臂主动安全

传统机械臂避障方法通常基于静态环境或执行前路径检查，难以处理障碍物随时间变化的情况。本文方法通过时空风险占据预测，使机械臂能够提前感知未来潜在风险，并主动调整轨迹。

### 4.2 人机协作场景中的连续安全运动

在人机协作、智能制造、服务机器人等场景中，人手、工具、物料或移动平台可能随时进入机械臂工作空间。本文方法的目标不是简单急停，而是使机械臂在风险可控范围内继续生成安全轨迹，提高任务连续性和效率。

### 4.3 机械臂本体全身避障

实际碰撞往往发生在机械臂大臂、小臂、肘部或腕部，而不是只发生在末端执行器。本文提出的构型耦合风险模型关注机械臂本体各连杆安全，避免了只考虑末端避障的局限。

### 4.4 感知与规划的紧耦合

本文将感知模块输出的障碍物占据信息转化为轨迹优化中的连续风险代价，实现从“看见障碍物”到“生成安全轨迹”的完整闭环。

## 5. 主要创新点

建议将论文贡献写成 3 个核心创新点。

### 创新点 1：基于 URDF/Mesh 表面点云的构型耦合时空风险占据建模

提出一种面向机械臂全身安全的构型耦合时空风险占据模型。首先从 URDF 加载各连杆 Mesh，并在连杆局部坐标系中均匀预采样表面点；在线阶段只需根据实时关节状态执行正运动学变换，即可得到当前构型下的机器人全身表面点云。随后利用 KD-tree 查询机器人表面点云与静态/动态障碍占据之间的最近距离，将环境风险映射到构型空间中。现有实现按连杆分配采样点，后续可进一步按 Mesh 表面积分配以改善采样均匀性。

核心思想为：

```text
环境空间风险  →  机械臂构型风险

R_env(x, t)  →  R_body(q, t)
```

其中：

- `R_env(x, t)` 表示空间点 `x` 在时间 `t` 的环境风险；
- `R_body(q, t)` 表示机械臂处于构型 `q` 时在时间 `t` 的全身风险。

该创新点强调：

```text
1. 风险是时空耦合的，不是静态距离；
2. 风险是构型耦合的，不是单纯环境地图；
3. 风险作用于 URDF/Mesh 描述的机械臂全身真实外形，不是只作用于末端执行器；
4. 同一机器人表面表示同时服务于自身点云剔除、风险距离评价和轨迹优化，减少模型不一致。
```

### 创新点 2：URDF/Mesh 全身风险驱动的 NUBS 连续轨迹优化方法

提出一种风险驱动的非均匀 B 样条轨迹优化方法。NUBSTrajectory 负责根据起终状态、中间构型和分段时间生成 minimum jerk 连续轨迹，并提供轨迹能量及梯度传播能力；本文在其外部构建目标到达、关节约束和 URDF/Mesh 全身时空风险代价，再使用 L-BFGS 等数值优化器分阶段优化中间构型与时间分配：先固定 `T` 优化 `P_inner`，待静态风险优化稳定后再开放 `T`，最后才进行动态风险下的 `P_inner + T` 联合优化。

完整优化目标可表示为：

```text
J = J_smooth 
  + λ_t J_time
  + λ_r J_risk
  + λ_g J_goal
  + λ_q J_q
  + λ_v J_v
  + λ_a J_a
```

其中：

```text
J_smooth：轨迹平滑代价
J_time：执行时间代价
J_risk：时空风险代价
J_goal：目标到达误差
J_q：关节位置约束惩罚
J_v：关节速度约束惩罚
J_a：关节加速度约束惩罚
```

最关键的风险项为：

```text
J_risk = ∫ R_body(q(t), t) dt
```

该项使轨迹优化器不仅优化轨迹平滑性和目标到达，还能够根据未来风险主动调整机械臂构型。文中应将该方法表述为“风险代价驱动的轨迹优化”；只有在采用显式不等式约束并验证可行性时，才使用“严格安全约束”表述。

### 创新点 3：低频风险触发重规划与高频安全保护协同机制

动态障碍物会随时间运动，单次离线规划无法覆盖执行期间的全部环境变化。但持续高频运行全量 Mesh 点云和 NUBS 优化计算开销较大，因此本文采用多频率协同机制：感知前端持续更新对象级时空风险，规划层仅在未来轨迹风险超过阈值时触发低频局部重规划，执行层持续运行已有的速度缩放、构型排斥和急停保护。

每个规划周期内，系统根据最新 RGB-D 感知结果预测未来短时域内的障碍风险分布，并以机械臂当前状态作为初始边界条件，对未来轨迹进行局部优化。机械臂仅执行当前轨迹的前一小段，并在下一感知周期重新评估风险和更新轨迹。

核心流程为：

```text
感知更新
    ↓
风险预测
    ↓
当前轨迹风险评估
    ↓
低频局部重规划
    ↓
轨迹跟踪 + 高频调速/排斥/急停
    ↓
下一周期继续更新
```

当风险处于中等水平且计算预算允许时触发局部重规划；当障碍突然进入或优化超时、失败时，高频安全层立即减速或停止。该机制不依赖规划器在每个控制周期内都成功完成，更符合当前工程基础和真实机器人安全需求。

## 7. 方法内容设计

## 7.1 环境感知与障碍物提取

感知模块可采用高可行性路线，不需要过度依赖复杂神经网络。

推荐流程：

```text
RGB-D 相机
    ↓
无效点去除、工作空间裁剪与体素降采样
    ↓
URDF/Mesh 构型点云剔除与可选平面去除
    ↓
静态障碍分割
    ↓
动态障碍检测与跟踪
    ↓
生成时空占据风险场
```

可实现方式：

```text
1. 使用 RGB-D 相机获取点云；
2. 去除无效点，并利用相机外参将点云变换到机器人基坐标系；
3. 根据工作空间范围裁剪点云并进行体素降采样；
4. 根据实时关节状态生成 URDF/Mesh 机器人表面点云，并从混合点云中剔除机器人自身点；
5. 对固定桌面场景可选用 RANSAC 去除平面；
6. 使用 DBSCAN 聚类提取障碍对象；
7. 使用最近邻关联、位置 EMA、运动门限和速度死区进行对象跟踪与速度估计；
8. 对动态障碍进行匀速短时预测，并随预测时间扩大风险占据。
```

该模块作为支撑模块，重点不是提出新的感知算法，而是为风险占据建模提供可靠输入。

## 7.2 静态障碍空间风险建模

对静态障碍，可根据空间点到障碍物的距离定义风险：

```text
R_s(x) = exp(-d_s(x)^2 / σ_s^2)
```

其中：

- `x` 表示空间点；
- `d_s(x)` 表示空间点到最近静态障碍物的距离；
- `σ_s` 控制风险扩散范围。

距离越小，风险越高；距离大于安全距离后风险趋近于零。

也可以使用分段惩罚函数：

```text
Φ(d) = 0,                       d ≥ d_safe
Φ(d) = (d_safe - d)^2,           d < d_safe
```

其中 `d_safe` 为安全距离阈值。

---

## 7.3 动态障碍时空风险建模

对动态障碍，首先根据感知结果估计其当前状态：

```text
p_o(t), v_o(t)
```

其中：

- `p_o(t)` 为动态障碍当前位置；
- `v_o(t)` 为动态障碍速度。

短时预测采用匀速模型：

```text
p_o(t + τ) = p_o(t) + v_o(t) τ
```

动态障碍风险可表示为：

```text
R_d(x, t + τ) = exp(-||x - p_o(t + τ)||² / σ_d²)
```

其中：

- `τ` 为未来预测时间；
- `σ_d` 为动态障碍风险扩散尺度。

综合环境风险场为：

```text
R_env(x, t) = α_s R_s(x) + α_d R_d(x, t)
```

其中：

- `α_s` 为静态风险权重；
- `α_d` 为动态风险权重。

若考虑动态障碍预测不确定性，可以使风险扩散尺度随预测时间增大：

```text
σ_d(t + τ) = σ_0 + kτ
```

即预测时间越远，不确定性越大，风险区域越宽。该模型用于构建短时间窗口内的保守未来占据，不用于声称能够准确预测任意人类或障碍物运动。实验应限定在匀速或短时近似匀速的移动物体、人手缓慢进入和移动后短暂停留等场景，并通过随预测时间增大的风险扩散补偿模型误差。

## 7.4 基于 URDF/Mesh 的机器人本体表面点云建模

当前工程已经能够从 URDF 读取连杆层级、关节变换和 Mesh 几何，因此本文不再把胶囊体或球串作为主模型，而采用与真实机器人外形更一致的构型相关表面点云。

### 7.4.1 连杆局部表面预采样

对第 `l` 个连杆的 Mesh 表面，在其局部坐标系中一次性均匀采样：

```text
S_l^local = {s_l,1, s_l,2, ..., s_l,N_l}
```

采样数量 `N_l` 可按 Mesh 表面积分配。局部采样在系统初始化时完成，运行时不再重复读取 Mesh 或执行表面采样。

### 7.4.2 当前构型下的全身表面点云

给定关节构型 `q`，通过 URDF 正运动学计算各连杆变换 `T_l(q)`：

```text
x_l,k(q) = T_l(q) s_l,k
S_R(q) = union_l {x_l,k(q)}
```

其中 `S_R(q)` 是当前构型下的机器人全身表面点云。该表示覆盖基座、大臂、小臂、腕部、法兰和夹爪等实际 Mesh 几何，比规则胶囊体更适合描述复杂末端和非轴对称连杆。

### 7.4.3 分辨率与实时性

同一套局部高密度样本可派生不同分辨率：

```text
高密度点云：用于离线参考距离、图示和最终安全复核
中密度点云：用于风险代价与局部重规划
低密度点云：用于在线快速筛选和风险触发
```

通过体素降采样、按连杆缓存和只更新受关节影响的下游连杆控制计算量。胶囊体可保留为速度基线或快速粗筛方法，但不作为论文主方法的机器人几何表达。

## 7.5 构型耦合机械臂全身风险映射

令环境障碍点云或预测风险点集为 `O(t)`。对当前构型的机器人表面点 `x_l,k(q)`，其最近环境距离定义为：

```text
d_l,k(q,t) = min_{o in O(t)} ||x_l,k(q) - o||
```

工程实现中为 `O(t)` 建立 KD-tree，并批量查询机器人表面点到障碍点云的最近距离。机器人全身有效距离为：

```text
D_min(q,t) = min_l,k d_l,k(q,t)
```

`D_min(q,t)` 保留为安全评价、实验报告和候选轨迹复核指标，不直接作为主要优化目标。用于轨迹优化时，为避免单个最近点切换造成代价不连续，对安全阈值内的多个表面点进行平滑聚合：

```text
R_body(q,t) = Σ_l Σ_k w_l,k ρ(d_safe - d_l,k(q,t))
```

其中 `ρ(z)` 采用平滑 hinge、softplus 或分段二次函数，并在 `z<=0` 时趋近于零。风险计算至少输出：

```text
D_min(q,t)：全身最小距离
link_min：最近风险连杆
x_robot*, x_obs*：最近机器人表面点与障碍点
R_body(q,t)：用于优化的平滑风险代价
```

因此全文统一遵循：

```text
安全评价与轨迹复核：D_min
优化目标与梯度计算：R_body
```

优化结束后，即使 `R_body` 已明显下降，也必须使用更密集的时间采样和高密度 Mesh 表面点云重新计算 `D_min`，未通过复核的候选轨迹不得进入执行队列。

该表达强调：

> 同一个障碍物对机械臂的风险并不只取决于障碍物本身位置，而取决于机械臂当前构型下各连杆在空间中的位置。

因此，该模型体现了“构型耦合”。

## 7.6 NUBS minimum-control-effort 连续轨迹表示

机械臂轨迹在关节空间中表示为：

```text
q(t) = NUBS(P, T),    t ∈ [0, T_total]
```

其中：

```text
P_inner = {q1, q2, ..., qM-1}
T = {T1, T2, ..., TM}
```

- `P_inner` 为待优化的中间插值构型，而不是最终 B 样条控制点；
- `T` 为每段时间分配；
- `M` 为轨迹段数。

NUBSTrajectory 根据起终边界状态、`P_inner` 和 `T` 求解带状线性系统，内部恢复 B 样条控制点 `C`。因此外部优化器不直接维护 `C`，而优化更具有物理含义的中间构型和时间变量。

优化变量按以下顺序开放：

```text
阶段 A：固定均匀或人工给定的 T，仅优化 P_inner
阶段 B：静态风险优化稳定后，联合优化 P_inner 与 T
阶段 C：完成动态时间对齐验证后，再进行动态风险下的 P_inner 与 T 联合优化
```

阶段 A 是论文后端的首要最小实现，避免空间绕行和时间重分配同时引入后难以定位优化失败原因。

建议使用 minimum jerk 形式：

```text
J_smooth = ∫ ||q'''(t)||² dt
```

原因是机械臂运动通常需要速度、加速度连续，并避免过大的 jerk 引起机械冲击。

NUBS 轨迹后端主要承担：

```text
1. 连续时间轨迹表示；
2. 根据边界状态和中间构型恢复 B 样条控制点；
3. minimum-control-effort 能量及其梯度计算；
4. 将控制点梯度传播到中间构型和分段时间；
5. 速度、加速度、jerk 评估；
6. 风险代价积分的轨迹采样基础。
```

需要注意：

> NUBSTrajectory 是轨迹构造和梯度传播后端，不包含完整的障碍优化器。本文需要在其外部实现风险代价、机械约束和 L-BFGS 等优化循环。NUBS 与 MINCO 在相同边界和插值约束下可表示等价的 minimum-control-effort 轨迹，但论文实现应明确使用 NUBS 接口，不混写为一个现成的“NUBS/MINCO 优化器”。

## 7.7 风险代价驱动轨迹优化问题

完整轨迹优化问题可写为：

```text
min_{P,T} 
J = J_smooth 
  + λ_t J_time
  + λ_r J_risk
  + λ_g J_goal
  + λ_q J_q
  + λ_v J_v
  + λ_a J_a
```

上述是完整形式。第一版实现固定 `T`，实际求解 `min_{P_inner} J`；只有固定时间下的目标到达、静态避障、梯度正确性和收敛性均通过验证后，才使用 `min_{P_inner,T} J`。

其中：

### 平滑代价

```text
J_smooth = ∫ ||q'''(t)||² dt
```

### 时间代价

```text
J_time = T_total
```

### 目标到达代价

论文主体首先采用目标关节构型：

```text
J_goal = ||q(T_total) - q_goal||²
```

在接入并验证稳定逆运动学后，可扩展为末端位姿目标：

```text
J_goal = ||f_ee(q(T_total)) - x_goal||²
```

### 风险代价

```text
J_risk = ∫ R_body(q(t), t) dt
```

离散实现为：

```text
J_risk ≈ Σ_i R_body(q(t_i), t_i) Δt
```

风险梯度按照以下三级路线逐步实现。

### 第一级：全关节有限差分

第一版直接复用现有构型有限差分：

```text
∂R_body/∂q_j ≈ [R_body(q + εe_j,t) - R_body(q - εe_j,t)] / (2ε)
```

随后利用 NUBS 基函数和梯度传播接口，将采样时刻的构型风险梯度累积到 `P_inner` 与 `T`。该方案只用于离线正确性验证和小规模静态实验，不作为在线实时性的最终实现。

### 第二级：风险窗口与风险连杆局部有限差分

仅对满足以下条件的轨迹采样点和关节维度计算有限差分：

```text
1. D_min(q(t_i),t_i) < d_activate 的风险时间窗；
2. 最近风险连杆及其上游可影响关节；
3. 距离当前风险对象较近的局部 Mesh 子集。
```

该阶段用于争取约 `1 Hz` 的风险触发重规划能力，并通过与全量有限差分的梯度方向、风险降低量和候选轨迹结果对比验证近似误差。

### 第三级：最近表面点与连杆 Jacobian 半解析梯度

对最近机器人表面点 `x_r(q)` 和障碍点 `x_o(t)`，使用连杆点 Jacobian `J_x(q)` 传播距离梯度：

```text
∂d/∂q = [(x_r - x_o) / ||x_r - x_o||]^T J_x(q)
```

再结合平滑风险函数 `ρ` 和 NUBS 梯度传播获得对 `P_inner` 与 `T` 的梯度。该阶段用于降低在线优化开销，并在实测稳定后再尝试将重规划频率从约 `1 Hz` 提高到 `1-5 Hz`。

### 关节位置约束惩罚

```text
J_q = Σ_i Φ(q(t_i) - q_max) + Φ(q_min - q(t_i))
```

### 关节速度约束惩罚

```text
J_v = Σ_i Φ(|qdot(t_i)| - qdot_max)
```

### 关节加速度约束惩罚

```text
J_a = Σ_i Φ(|qddot(t_i)| - qddot_max)
```

其中 `Φ(·)` 为平滑惩罚函数，例如：

```text
Φ(x) = 0,       x ≤ 0
Φ(x) = x²,      x > 0
```

## 7.8 风险触发的分层在线运动更新策略

动态障碍物存在时，轨迹不能只在任务开始前检查一次。但考虑到 Mesh 表面风险评估和非线性轨迹优化的计算开销，本文采用事件触发、多频率分层更新，而不要求每个控制周期都执行完整重规划。

### 基本思想

每个规划周期执行以下步骤：

```text
Step 1：读取机械臂当前状态 q_now, qdot_now, qddot_now

Step 2：获取最新 RGB-D 感知结果

Step 3：预测未来 H 秒内的动态障碍风险占据

Step 4：评估当前正在执行轨迹的未来风险

Step 5：若风险低于阈值，继续跟踪当前轨迹

Step 6：若进入预警区且剩余时间充足，以当前状态和上一轨迹为 warm start，低频优化剩余轨迹

Step 7：若进入高风险区、优化超时或优化失败，高频安全层立即缩放速度、施加排斥速度或停止

Step 8：仅当目标误差、安全距离、运动学限制、求解时限、高密度 Mesh 复核和轨迹连续性全部合格时，才切换新轨迹
```

候选轨迹接受条件统一写为：

```text
Accept(q_new) = GoalOK and DistanceOK and LimitsOK
                and SolverOK and ValidationOK and ContinuityOK
```

该条件同时用于算法实现、虚拟闭环统计和真实机械臂阶段 C，避免不同实验使用不同的“成功”定义。

### 初始边界条件

每次重规划时，新轨迹必须与当前机械臂状态平滑衔接：

```text
q_new(0)     = q_now
qdot_new(0)  = qdot_now
qddot_new(0) = qddot_now
```

### 终端条件

论文主体的终端条件统一设置为：

```text
q_new(H) ≈ q_goal
```

任务空间目标只作为后续扩展：先由外部 IK 模块生成 `q_goal`，不在 CCRO-NUBS 主优化问题中直接引入 `x_goal`。

### 多频率协同与风险触发策略

可以设置三种状态：

```text
低风险：
继续执行当前轨迹

中风险：
触发低频局部重规划，执行层同时限制速度

高风险：
立即减速或停止；只有在风险解除或新轨迹通过复核后恢复运动
```

建议的初始工程目标为：感知更新 `10-30 Hz`，快速风险检查与安全控制不低于现有控制循环频率，第一版风险触发重规划目标约为 `1 Hz`。只有在风险窗口筛选或半解析梯度实现后，再评估提高到 `1-5 Hz`。本文不要求每个控制周期均完成完整非线性轨迹优化；高频安全层独立于 NUBS 优化器运行，避免优化超时或失败直接转化为危险控制输出。

## 8. 算法伪代码

```text
Algorithm: URDF/Mesh Risk-Aware Event-Triggered NUBS Planning

Input:
    Current robot state q_now, qdot_now, qddot_now
    Target configuration q_goal
    RGB-D observation Z_t
    URDF model and pre-sampled local mesh surfaces S_local
    Previous trajectory q_prev(t)

Output:
    Updated reference trajectory q_ref(t)

1. Acquire RGB-D observation Z_t and current joint state q_now
2. Transform S_local by URDF forward kinematics to obtain S_R(q_now)
3. Remove robot self points from Z_t using the Mesh surface KD-tree
4. Cluster and track external objects; estimate p_o(t), v_o(t)
5. Predict obstacle occupancy O(t + τ) in horizon H
6. Sample q_prev(t) and evaluate URDF/Mesh full-body future risk
7. If trajectory risk is below the replanning threshold:
       q_ref(t) ← q_prev(t)
   Else:
       Initialize P_inner and T from the previous NUBS trajectory
       Set boundary conditions:
           q(0)     = q_now
           qdot(0)  = qdot_now
           qddot(0) = qddot_now
       Optimize P_inner with fixed T in the first implementation;
       enable joint P_inner and T optimization only after validation:
           minimize J = J_smooth + λ_t J_time + λ_r J_risk
                        + λ_g J_goal + λ_q J_q + λ_v J_v + λ_a J_a
       Check solver completion within the time budget
       Validate goal error, q/qdot/qddot limits, and start-state continuity
       Validate D_min with a denser Mesh surface and finer time sampling
       if GoalOK and DistanceOK and LimitsOK and SolverOK
          and ValidationOK and ContinuityOK:
           q_ref(t) ← optimized NUBS trajectory
       else:
           keep safety-limited execution or stop
8. In every control cycle, apply speed scaling / repulsion / emergency stop
9. Execute the accepted reference for a short interval and repeat
```

## 10.4 实验 4：静态障碍下 Mesh 全身风险 NUBS 规划

### 目的

验证 URDF/Mesh 全身风险代价能够引导 NUBS 轨迹绕开静态点云障碍，并分析安全距离、平滑性与计算量之间的权衡。

### 场景设计

```text
场景 A：障碍物位于末端原始路径附近；
场景 B：障碍物位于肘部或小臂附近；
场景 C：多个静态障碍形成狭窄通道。
```

### 对比方法

```text
1. 原始 NUBS，无风险项；
2. NUBS + 末端 Mesh 风险；
3. NUBS + URDF/Mesh 全身风险；
4. RRT-Connect + 时间参数化（具备统一碰撞模型后作为扩展基线）。
```

### 评价指标

```text
规划成功率
全身最小安全距离
风险积分
风险降低率
平均/95 分位规划时间
任务完成时间
目标误差
轨迹长度、任务时间和 jerk 相对增量
优化失败率与候选轨迹复核失败率
关节约束违反次数
```

风险降低率定义为：

```text
R_risk_reduce = (J_risk_before - J_risk_after) / max(J_risk_before, epsilon)
```

同时以无风险 NUBS 为参考，报告路径长度增加比例、任务时间增加比例和 jerk 增加比例，用于说明提高安全距离所付出的绕行与平滑性代价。

### 预期结论

```text
1. 无风险 NUBS 只能保证平滑，不能保证避障；
2. 末端风险会遗漏中间连杆危险；
3. Mesh 全身风险能够提高全身安全距离，但会增加优化时间。
```

## 10.6 实验 6：真实机械臂分阶段系统验证

真实系统验证分三步进行，避免未经验证的规划结果直接控制机械臂：

```text
阶段 A：影子模式，只计算风险和候选轨迹，不发送运动指令；
阶段 B：执行原参考轨迹，高频安全层可调速或停止，NUBS 只提供候选轨迹；
阶段 C：候选轨迹通过高密度 Mesh 点云复核后，允许低频切换执行。
```

阶段 C 的候选轨迹必须同时通过以下切换门槛：

```text
1. 目标误差：||q(T)-q_goal|| <= epsilon_goal；
2. 安全复核：高密度 Mesh 与细时间采样下 D_min >= d_stop；
3. 运动学限制：q、qdot、qddot 均不超限；
4. 求解状态：优化在时间预算内正常结束，非超时或数值失败结果；
5. 轨迹连续性：新轨迹起点 q、qdot、qddot 与当前执行状态连续；
6. 切换可执行性：轨迹时间戳单调，控制周期内不存在位置或速度突跳。
```

任一条件不满足时均拒绝切换，由原轨迹的安全限速状态或急停策略继续接管。报告真实任务完成率、全身最小距离、轨迹跟踪误差、安全层介入次数、规划超时率、候选轨迹拒绝率和端到端耗时。只有阶段 C 达到预设安全与实时性判据后，才宣称具备真实动态重规划能力。

## 13. 实现路线

建议在现有感知与安全控制基础上，按照以下四个增量阶段实现。每个阶段均形成可独立验证的实验结果，不以后续阶段完成作为前置条件。

### 已有工程基础

```text
1. RGB-D 点云读取、坐标变换、工作空间裁剪和体素降采样；
2. URDF/Mesh 连杆局部表面预采样与实时 FK 构型变换；
3. KD-tree 机器人自身点云剔除和全身最近距离查询；
4. DBSCAN 对象提取、最近邻跟踪、EMA 速度估计和匀速短时预测；
5. 构型有限差分风险梯度、排斥速度、速度缩放和急停保护；
6. 第 4.2-4.6 节实验脚本、录制数据、虚拟闭环和指标统计框架。
```

### 最小可行闭环与论文成立节点

论文后端部分按以下最小闭环推进：

```text
步骤 1：q_start -> q_goal 的无障碍 minimum jerk NUBS 轨迹
步骤 2：静态点云下的 URDF/Mesh 全身风险代价优化
步骤 3：录制动态障碍序列下的时空风险轨迹优化
步骤 4：虚拟闭环或真实系统影子模式下的风险触发候选轨迹重规划
```

完成步骤 4，并给出目标到达、安全距离、风险降低率、优化时间和失败率等完整结果后，论文“构型耦合时空风险进入连续轨迹优化”的主体即可成立。真实机械臂自动切换执行属于增强验证，不作为证明方法成立的唯一前提。

## 阶段 1：离线 NUBS 轨迹优化打通

### 目标

给定 `q_start` 和 `q_goal`，生成 minimum jerk NUBS 轨迹。

### 实现内容

```text
1. 读取机械臂关节限制；
2. 通过 C++ 原生接口或 pybind11 调用 NUBSTrajectory 生成 `q(t)`；
3. 评估 q, qdot, qddot, jerk；
4. 加入目标误差和平滑代价；
5. 固定均匀或人工给定的 `T`，使用 L-BFGS 仅优化 `P_inner`；
6. 通过 NUBS/MINCO 一致性和外部有限差分验证梯度。
```

### 阶段结果

```text
机械臂能够在无障碍环境中生成平滑、连续、满足关节限制的轨迹。
```

---

## 阶段 2：加入静态障碍全身风险代价

### 目标

机械臂能够避开桌面静态障碍物。

### 实现内容

```text
1. 直接复用 RobotPointRemover 的各连杆局部 Mesh 表面预采样；
2. 对每个轨迹采样构型执行 URDF FK，生成中/低密度全身表面点云；
3. 为静态障碍点云建立 KD-tree，计算各表面点最近距离；
4. 使用平滑 hinge/softplus 构建 `J_risk`；
5. 固定 `T`，第一版复用现有构型有限差分梯度优化 `P_inner`；
6. 用高密度 Mesh 表面点云和更细时间采样复核候选轨迹；
7. 固定时间版本稳定后，再开展静态风险下 `P_inner + T` 联合优化；
8. 评估采样密度、距离误差和优化时间之间的关系。
```

### 阶段结果

```text
机械臂能够在静态障碍环境下降低全身风险，并在高密度 Mesh 复核中满足 `D_min >= d_stop`、目标误差和关节运动学判据。
```

---

## 阶段 3：加入动态障碍时空风险

### 目标

轨迹优化能够考虑障碍物未来位置。

### 实现内容

```text
1. 复用 OccupancyTracker 的位置/速度估计和运动门限；
2. 复用 predict_risk_spheres 的匀速中心预测和不确定性膨胀；
3. 将预测风险球或预测对象点云按 `τ` 与轨迹采样时刻对齐；
4. 在 `q(τ)` 对应的 Mesh 全身表面点云上查询时变风险；
5. 先固定 `T` 优化 `P_inner`，验证动态障碍时间对齐和风险梯度；
6. 在固定时间版本稳定后，再开放 `T` 并评估 `P_inner + T` 联合优化；
7. 先在录制序列和虚拟闭环中验证，不直接控制真实机械臂。
```

### 阶段结果

```text
机械臂能够在录制动态序列或虚拟闭环中生成风险低于原始轨迹的候选轨迹，并定量报告短时匀速预测的适用范围、误警代价和预测失配案例。
```

---

## 阶段 4：风险触发低频重规划与高频安全保护协同

### 目标

在不削弱现有安全控制能力的前提下，实现动态环境中的事件触发轨迹更新。

### 实现内容

```text
1. 固定规划时域 `H=2-4 s`，持续评估当前轨迹未来风险；
2. 低风险时不优化，继续跟踪当前轨迹；
3. 中风险时用上一轮 `P_inner` 和 `T` warm start，只优化剩余轨迹；第一版固定剩余分段时间，仅更新 `P_inner`；
4. 第一版重规划频率目标设为约 `1 Hz`，并设置优化超时预算；只有局部有限差分或半解析梯度达到实测要求后，再提高到 `1-5 Hz`；
5. 高风险、超时或求解失败时，由现有速度缩放、排斥和急停层接管；
6. 候选轨迹通过高密度 Mesh 点云复核后再切换；
7. 依次完成影子模式、虚拟闭环和真实机械臂受控验证；
8. 后续使用连杆 Jacobian、风险对象筛选和局部时间窗提高频率。
```

### 阶段结果

```text
机械臂能够在风险出现时低频调整未来轨迹，并在规划尚未完成或失败时由高频安全层维持保守运动状态。只有实测端到端耗时和成功率达到判据后，再将其表述为实时在线重规划。
```

## 14. 与动态抓取论文的关系和区别

参考动态抓取论文主要面向传送带移动目标抓取，其核心是动态目标终端约束、时间最优和 minimum jerk 平衡。本文不以单一移动目标抓取为主任务，而是面向动态复杂环境中的机械臂全身安全运动生成。

二者区别如下：

| 对比方面 | 动态抓取论文 | 本文工作 |
|---|---|---|
| 主任务 | 移动目标 pick-and-place | 动态环境安全运动生成 |
| 感知对象 | 主要是目标物体 | 静态障碍 + 动态障碍 |
| 安全对象 | 避免碰撞，偏任务场景 | 机械臂全身连杆风险 |
| 轨迹目标 | 快速抓取动态目标 | 安全到达目标关节构型 `q_goal` |
| 风险模型 | 碰撞/约束惩罚 | 构型耦合时空风险占据 |
| 在线机制 | 在线感知与规划 | 风险触发低频重规划 + 高频安全保护 |
| 应用扩展 | 动态抓取 | 人机协作、动态避障、取放、抓取 |

本文可以将动态抓取作为应用验证场景之一，但不建议将其作为全文唯一主线。

## 15. 论文摘要雏形

本文面向动态复杂环境下机器人操作臂从起始构型安全到达目标构型的运动生成问题，研究一种基于构型耦合时空风险占据与非均匀 B 样条优化的轨迹生成方法。针对传统机械臂运动规划难以同时考虑动态障碍时空变化、机械臂本体全身安全和轨迹连续可执行性的问题，首先利用 RGB-D 感知信息完成机器人自身点云解耦、外部对象提取、跨帧跟踪与短时运动预测。随后从机器人 URDF 加载各连杆 Mesh，在局部坐标系中预采样表面点，并依据实时关节状态通过正运动学生成当前构型下的全身表面点云；通过 KD-tree 最近距离查询，将静态和动态障碍的保守短时未来占据映射为机械臂构型相关的全身时空风险。在此基础上，以 NUBSTrajectory 作为 minimum jerk 连续轨迹构造和梯度传播后端，在其外部构建包含平滑性、执行时间、目标到达、关节运动学限制和全身时空风险的代价函数。为提高真实系统可实现性，进一步采用风险触发的低频局部重规划与高频速度缩放、构型排斥和急停保护相结合的分层在线机制。实验将分别验证 URDF/Mesh 外部占据解耦、对象级动态预警、全身风险梯度、静态与动态 NUBS 轨迹优化、虚拟闭环/影子模式重规划以及真实机械臂分阶段执行性能，并同时报告目标到达率、最小安全距离、风险降低率、轨迹偏离代价、优化超时与复核失败率、安全层接管次数和端到端耗时。

## 16. 关键结论

本文主线应明确为：

> 基于构型耦合时空风险占据与 NUBS 轨迹优化的机械臂动态安全运动生成方法。

最终形成的技术闭环为：

```text
环境感知
    ↓
静态/动态障碍提取
    ↓
时空风险占据建模
    ↓
机械臂全身构型风险映射
    ↓
风险代价驱动 NUBS 连续轨迹优化
    ↓
规划层：风险触发低频局部重规划
执行层：高频速度级安全保护
    ↓
安全、平滑、可执行的机械臂运动
```

论文最重要的创新不是使用 NUBS，也不是单独做感知，而是：

> 复用同一套 URDF/Mesh 构型表面点云，将机器人自身点云解耦、全身风险评估和 NUBS 轨迹优化连接起来，并通过风险触发低频规划与高频安全保护协同，提高动态环境下机械臂运动的安全性、平滑性和工程可落地性。

推荐将论文主线凝练为：

> 本文提出一种面向动态环境的机械臂构型耦合时空风险占据建模与 NUBS 风险代价驱动轨迹优化方法。该方法基于 URDF/Mesh 表面点云建立机械臂全身风险表示，将 RGB-D 感知获得的静态/动态障碍保守未来占据映射为构型相关风险，并嵌入 minimum jerk NUBS 连续轨迹优化。在执行层，通过风险触发低频重规划与高频速度级安全保护协同，实现机械臂在动态障碍环境下安全、平滑、可执行的目标到达运动。

动态抓取可以作为应用场景之一，但更建议将主任务设定为动态环境下的安全到达、动态避障取放或人机协作安全运动。
