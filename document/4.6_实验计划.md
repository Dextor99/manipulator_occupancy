# 4.6 消融实验与实时性分析 — 实施计划

## 1. 实验目的

通过简化消融实验验证三个核心模块（时空风险预测、排斥向量、速度级安全滤波）对系统性能的贡献，并通过实时性分析评价方法的在线运行能力。**本节不复现前文所有实验**，而是复用 4.3 和 4.5 的动态障碍物序列与闭环实验日志。

### 4.3 `experiments/exp_46_main.py` — 实验入口

```python
def main():
    """从 4.3 和 4.5 结果聚合消融表 + 实时性表
       用法: python -m experiments.exp_46_main
             --results-43 results/43
             --results-45 results/45
             --timing-logs results/45/timing_logs
             --output results/46
    """
    # 1. 加载消融数据
    ablation = AblationMetrics(args.results_43, args.results_45)
    table_47 = ablation.build_ablation_table()

    # 2. 打印表 4-7（LaTeX 格式）
    #    ┌─────────────────┬────────┬────────┬───────┬─────────┬─────────┬────────┐
    #    │ Version         │ T_lead↑│D_min^ref│T_viol↓│R_avoid↑│R_timeout│J_q^rms↓│
    #    ├─────────────────┼────────┼────────┼───────┼─────────┼─────────┼────────┤
    #    │ Full            │  0.35  │  0.12  │ 0.02  │  1.00   │  0.00   │  0.08  │
    #    │ w/o Temporal... │  0.18  │  0.12  │ 0.02  │  1.00   │  0.00   │  0.08  │
    #    │ ...             │  ...   │  ...   │ ...   │  ...    │  ...    │  ...   │
    #    └─────────────────┴────────┴────────┴───────┴─────────┴─────────┴────────┘

    # 3. 加载实时性数据
    timing = TimingAnalyzer(args.timing_logs)
    timing_stats = timing.compute_timing_stats()
    e2e_stats = timing.compute_e2e_stats()

    # 4. 打印表 4-8 + 表 4-9（LaTeX 格式）

    # 5. 输出 JSON
    with open(f"{args.output}/ablation.json", "w") as f:
        json.dump(table_47, f, indent=2)

    with open(f"{args.output}/timing.json", "w") as f:
        json.dump({"timing": timing_stats, "e2e": e2e_stats}, f, indent=2)
```

## 5. 实时性数据采集方式

### 5.1 在 4.5 实验运行器中埋点

在 `exp_45_runner.py` 的每帧处理循环中加入计时：

```python
class TimedFrameProcessor:
    """带计时包装的帧处理器"""

    def process_one_frame(self, camera_frame, robot_state, dt) -> dict:
        t0 = time.perf_counter()

        # 点云预处理
        points_base = transform_points(camera_frame.points_cam, self.extrinsic)
        points_cropped = crop_workspace(points_base, self.workspace)
        t1 = time.perf_counter()

        # 外部占据解耦
        external_pts, robot_pts = self.self_filter.remove(points_cropped, robot_state)
        t2 = time.perf_counter()

        # 对象聚类与建模
        clusters = cluster_points(external_pts, eps=0.05, min_points=25)
        objects = [make_occupancy_object(c, timestamp) for c in clusters]
        t3 = time.perf_counter()

        # 对象关联与速度估计
        tracked = self.tracker.update(objects, timestamp)
        t4 = time.perf_counter()

        # 时空风险预测
        risk_spheres = predict_risk_spheres(tracked, horizon=0.5, step=0.1)
        t5 = time.perf_counter()

        # 风险距离与排斥向量
        distance, nearest_id = min_capsule_sphere_distance(self.capsules, risk_spheres)
        rep_velocity = self.compute_repulsion(tracked, robot_state)
        t6 = time.perf_counter()

        # 安全运动生成
        velocity_cmd = self.controller.step(external_pts, tracked, robot_state, dt)
        t7 = time.perf_counter()

        timing = {
            "T_pre":  (t1 - t0) * 1000,   # ms
            "T_dec":  (t2 - t1) * 1000,
            "T_obj":  (t3 - t2) * 1000,
            "T_trk":  (t4 - t3) * 1000,
            "T_risk": (t5 - t4) * 1000,
            "T_rep":  (t6 - t5) * 1000,
            "T_cmd":  (t7 - t6) * 1000,
            "T_frame": (t7 - t0) * 1000,
        }

        return {"velocity_cmd": velocity_cmd, "timing": timing}
```

### 5.2 耗时日志格式

每帧的耗时记录为 CSV 格式：

```csv
frame_idx,T_pre_ms,T_dec_ms,T_obj_ms,T_trk_ms,T_risk_ms,T_rep_ms,T_cmd_ms,T_frame_ms
0,1.2,8.5,3.1,0.8,0.5,2.3,0.4,16.8
1,1.1,8.2,2.9,0.7,0.5,2.1,0.4,15.9
...
```

累积 ~3000 帧（约 100s 实验）后，用 `TimingAnalyzer` 计算统计量。

## 6. 消融数据映射

| 表 4-7 行 | T_lead 来源 | 闭环指标来源 |
|-----------|-------------|-------------|
| **Full** | 4.3: Ours 的 T_lead | 4.5: Ours-Full 的全部闭环指标 |
| **w/o Temporal Risk** | 4.3: Ours-w/o Temporal 的 T_lead | 复用 Full 的闭环指标（仅在预警维度有差异） |
| **w/o Repulsive Vector** | 4.3: Ours 的 T_lead（仍有 Temporal Risk） | 4.5: Ours-Scale 的全部闭环指标 |
| **w/o Safety Filter** | 4.3: Ours 的 T_lead（仍有 Temporal Risk） | 4.5: Ours-Rep 的全部闭环指标 |

**说明**：
- `w/o Temporal Risk` 只影响预警提前时间，不影响闭环运动表现，因此闭环指标复用 Full
- `w/o Repulsive Vector` 和 `w/o Safety Filter` 不影响预警（Temporal Risk 仍在），因此 T_lead 复用 Full 值
- 这种设计确保每个消融版本只在它去掉的模块维度上有差异

### 10.0 对比/消融版本复现说明

4.6 本身不重新运行机器人实验，而是复用 4.3 和 4.5 中已经复现好的对比版本。各消融版本与前文方法的对应关系如下：

| 4.6 消融版本 | 需要先运行的实验 | 对应文件/方法 |
| --- | --- | --- |
| Full | 4.3 `ours` + 4.5 `ours_full` | `data/results/ch4_3/metrics.json` 和 `trial_*_ours_full_*.json` |
| w/o Temporal Risk | 4.3 `ours_wo_temporal` + 4.5 `ours_full` | 只在预警提前时间上替换为无时空预测版本 |
| w/o Repulsive Vector | 4.3 `ours` + 4.5 `ours_scale` | 闭环指标来自仅速度缩放版本 |
| w/o Safety Filter | 4.3 `ours` + 4.5 `ours_rep` | 闭环指标来自无速度级安全滤波版本 |

因此，4.6 前必须至少完成以下命令：

```bash
python -m experiments.exp_43_main \
  --record-dir data/recordings/ch4_3_dynamic_01 \
  --empty-record-dir data/recordings/ch4_3_empty \
  --output data/results/ch4_3
```

以及：

```bash
python -m experiments.exp_45_runner \
  --record-dir data/recordings/ch4_3_dynamic_01 \
  --empty-record-dir data/recordings/ch4_3_empty \
  --scenario B \
  --controller all \
  --trial-id 0 \
  --output data/results/ch4_5
```

这样 `exp_46_main.py` 才能从已有结果中拼出表 4-7 的四个消融版本。
