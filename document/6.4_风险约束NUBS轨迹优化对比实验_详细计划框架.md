## 6.4 小节定位

6.4 用于证明：本文提出的 CCRO-NUBS 不只是能计算风险距离，还能把构型耦合全身风险嵌入连续轨迹优化，生成满足目标、平滑性、关节约束和安全复核的轨迹。

本节回答：

```text
1. NUBS 后端是否满足边界、路点、梯度和关节约束；
2. 固定时间 NUBS 是否能稳定降低 jerk 能量；
3. 时间变量优化是否具备正确梯度和时间—平滑度权衡；
4. 加入风险项后，NUBS-base、仅末端风险和全身风险的轨迹安全性有何差异；
5. 参照原论文/经典方法复现 MINCO、RRT-Connect 等外部基线后，CCRO-NUBS 的安全性、平滑性和耗时特征如何。
```

## 6.4.2 时间变量优化实验

### 1. 实验目的

验证 NUBS 可以扩展为时间变量优化，并展示轨迹时长与平滑性之间的 Pareto 权衡。

### 2. 当前结果

表格：

```text
data/results/ch6_4/table_6_4_time_optimization.md
data/results/ch6_4/table_6_4_lambda_sweep.md
```

P2 时间优化结果：

| 方法 | 总时长 / s | jerk 能量 | 目标值 | 优化耗时 / ms |
|---|---:|---:|---:|---:|
| fixed | `6.0000` | `0.07013889` | `0.37013889` | `12.20` |
| total | `6.1582` | `0.06158182` | `0.36949092` | `5.20` |
| segment | `6.1582` | `0.06158182` | `0.36949092` | `6.49` |

梯度验证：

```text
total 时间梯度相对误差：5.566e-09
segment 时间梯度相对误差：1.368e-08
```

时间权重扫描：

| `lambda_time` | 总时长 / s | jerk 能量 |
|---:|---:|---:|
| `0.02` | `7.17424` | `0.02870` |
| `0.05` | `6.15818` | `0.06158` |
| `0.10` | `5.48632` | `0.10973` |
| `0.20` | `4.88775` | `0.19551` |

论文可写结论：

```text

这说明 NUBS 时间优化具有可解释的时间—平滑度权衡；
当前分段时间优化在无障碍对称场景下与总时长优化接近，后续可在动态风险场景中进一步发挥作用。
```

## 6.4.3 静态风险约束 NUBS 轨迹优化对比

### 1. 实验目的

验证风险代价进入 NUBS 优化后，轨迹能否通过 dense Mesh 独立复核。

对比方法：

| 方法 | 程序名称 | 含义 |
|---|---|---|
| NUBS-base | `baseline` | 只优化平滑性，不加入风险项 |
| NUBS-EEF-risk | `ee_only` | 只对末端/夹爪连杆加入风险项 |
| CCRO-NUBS | `full_body` | 对 URDF/Mesh 全身连杆加入风险项 |

场景：

| 场景 | 含义 | 预期 |
|---|---|---|
| A | 末端附近障碍 | 末端风险和全身风险均应通过 |
| B | 身体连杆附近障碍 | 仅末端风险应失败，全身风险应通过 |
| C | 多障碍混合场景 | 全身风险应获得更高安全裕度 |

### 2. 当前结果

表格：

```text
data/results/ch6_4/table_6_4_static_risk.md
```

关键结果：

| 场景 | 方法 | dense `D_min` / m | 是否通过 | 最近风险连杆 |
|---|---|---:|---|---|
| A | NUBS-base | `0.00030` | 否 | `right_link` |
| A | NUBS-EEF-risk | `0.08130` | 是 | `wrist2_Link` |
| A | CCRO-NUBS | `0.10647` | 是 | `wrist2_Link` |
| B | NUBS-base | `0.00044` | 否 | `foreArm_Link` |
| B | NUBS-EEF-risk | `0.00044` | 否 | `foreArm_Link` |
| B | CCRO-NUBS | `0.10162` | 是 | `foreArm_Link` |
| C | NUBS-base | `0.00029` | 否 | `gripper_base_link` |
| C | NUBS-EEF-risk | `0.05437` | 是 | `foreArm_Link` |
| C | CCRO-NUBS | `0.10294` | 是 | `foreArm_Link` |

论文可写结论：

```text
无风险 NUBS 虽然平滑并能到达目标，但不能保证避障；
仅末端风险在身体连杆障碍场景 B 中完全失效，dense D_min 仍约为 0.00044 m；
CCRO-NUBS 在 A/B/C 三类场景中均通过 dense 复核，且身体连杆场景 B 的 D_min 提升到 0.10162 m；
这证明构型耦合全身风险不仅能被计算，也能有效驱动 NUBS 轨迹优化。
```

### 3. 可解释代价

需要在论文中明确：

```text
全身风险会增加优化耗时和 jerk 能量；
这是安全裕度提升带来的代价，不应只用平滑性单指标评价轨迹优劣。
```

例如场景 B：

```text
NUBS-EEF-risk：D_min=0.00044 m，优化很快但失败；
CCRO-NUBS：D_min=0.10162 m，耗时约 6575 ms，通过 dense 复核。
```

## 6.4.4 外部规划基线复现结果

### 1. 复现依据与实现边界

本阶段已经补充外部规划基线复现程序：

```text
experiments/exp_64_external_baselines.py
planning/minco_trajectory.py
```

复现依据：

| 方法 | 原始来源 | 本项目复现方式 | 统一验证口径 |
|---|---|---|---|
| MINCO-base | Wang et al., *Geometrically Constrained Trajectory Optimization for Multicopters*, IEEE T-RO 2022；GCOPTER 官方实现 | 关节空间 `s=3` 最小 jerk MINCO，多段五次多项式，固定中间点解析轨迹 | dense Mesh `D_min`、关节约束、goal error |
| MINCO-risk | 同上 | MINCO 表示 + 与本文相同全身 `J_risk`，固定预算无导数局部扰动优化 | 同一 dense Mesh verifier |
| RRT-Connect + smoothing | Kuffner and LaValle, *RRT-Connect: An Efficient Approach to Single-Query Path Planning*, ICRA 2000 | 关节空间双向 RRT-Connect，shortcut 平滑，MINCO 时间参数化 | 同一 dense Mesh verifier |

论文中应明确：

```text
MINCO 原论文面向多旋翼平坦输出，本项目复现为机械臂关节空间最小控制量多项式基线；
RRT-Connect 复现为关节空间采样式几何规划，后接 shortcut 和 MINCO 时间化；
因此这两类方法用于“外部思想对照”和“同验证器公平评估”，不声称直接复用了多旋翼官方工程配置。
```

### 2. 外部基线当前结果

表格：

```text
data/results/ch6_4/table_6_4_external_baselines.md
data/results/ch6_4/table_6_4_rrt_multiseed.md
```

关键结果：

| 场景 | 方法 | dense `D_min` / m | 是否通过 | `J_smooth` | 耗时 / ms |
|---|---|---:|---|---:|---:|
| A | MINCO-base | `0.00022` | 否 | `1.25076` | `0` |
| A | MINCO-risk | `0.11135` | 是 | `3.72493` | `1015.65` |
| A | RRT-Connect + smoothing | `0.08490` | 是 | `0.98570` | `1362.22` |
| B | MINCO-base | `0.00038` | 否 | `1.25076` | `0` |
| B | MINCO-risk | `0.10994` | 是 | `3.72493` | `985.07` |
| B | RRT-Connect + smoothing | `0.09246` | 是 | `2.20123` | `1423.65` |
| C | MINCO-base | `0.00009` | 否 | `1.25076` | `0` |
| C | MINCO-risk | `0.18379` | 是 | `4.07090` | `1350.04` |
| C | RRT-Connect + smoothing | `0.05576` | 否 | `3.08066` | `2791.63` |

RRT-Connect 5 种子统计：

| 场景 | accepted rate | `D_min` mean ± std / m | `J_smooth` mean ± std | time mean ± std / ms |
|---|---:|---:|---:|---:|
| A | `1.00` | `0.08490 ± 0.02802` | `0.98570 ± 1.35475` | `1362.22 ± 345.72` |
| B | `1.00` | `0.09246 ± 0.03919` | `2.20123 ± 3.13956` | `1423.65 ± 448.43` |
| C | `0.60` | `0.05576 ± 0.03611` | `3.08066 ± 5.12824` | `2791.63 ± 617.95` |

论文可写结论：

```text
MINCO-base 和 NUBS-base 类似，在无风险约束下无法避免局部全身碰撞；
MINCO-risk 接入相同全身风险后可以通过 dense 安全复核，但 jerk 能量明显高于 CCRO-NUBS；
RRT-Connect + smoothing 在 A/B 中 5 个随机种子均通过 dense 复核，但场景 C accepted rate 仅 0.60，说明采样式路径在多障碍/窄通道条件下稳定性不足；
CCRO-NUBS 的优势在于直接在连续 NUBS 轨迹优化中耦合全身风险，安全裕度、连续性和后续滚动重规划接口更统一。
```

### 3. 和内部 CCRO-NUBS 表的合并方式

建议正文保留两张表：

```text
表 6-?：NUBS-base / NUBS-EEF-risk / CCRO-NUBS 内部消融；
表 6-?：MINCO-base / MINCO-risk / RRT-Connect+smoothing / CCRO-NUBS 外部基线综合对比。
```

注意不要只用 `J_smooth` 评价外部方法。RRT 的 jerk 和 D_min 方差较大，且不包含本文的时空风险闭环接口；应同时报告 accepted rate、dense D_min 和随机种子统计。
