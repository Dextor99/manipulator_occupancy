# 4.4 构型相关排斥向量离线验证实验计划与使用步骤

本计划用于完成第四章 4.4 节“构型相关排斥向量离线验证实验”。实验目标是验证：在 4.3 已经获得对象级风险占据和离线参考距离 `D_ref(q,t)` 的基础上，本文生成的排斥关节速度是否能够沿着“增大机器人与障碍物参考距离”的方向运动，并且是否能够对中间连杆附近的风险产生响应。

本节不做真实机器人闭环控制，只回放 4.3 录制序列并进行虚拟一步执行。因此 4.4 不会向真实机械臂发送运动指令，适合作为安全引导控制前的离线验证。

本次新增或完善的程序只放在 `experiments/` 目录下，不修改 4.2、4.3 的实验程序和已有结果。

---

## 1. 实验总体设计

4.4 的核心输入为 4.3 录制的动态障碍物序列。程序先复用 `ReferenceConstructor` 从录制数据中构造离线参考障碍物点云 `P_obs^ref(t)`，再根据机器人当前构型 `q_t` 计算参考风险距离：

```text
D_ref(q_t, t) = min distance(P_obs^ref(t), S_R(q_t))
```

其中 `S_R(q_t)` 是由 URDF/Mesh 表面采样和 FK 生成的机器人全身表面点云。`D_ref` 只用于离线评价，不参与 4.3 在线预警结果，也不参与真实机器人控制。

| 场景 | 用途 | 是否进入主定量表 |
| --- | --- | --- |
| 场景 A：末端附近风险 | 障碍物主要靠近 wrist/夹爪区域，验证排斥方向基本合理性 | 是 |
| 场景 B：中间连杆风险 | 障碍物主要靠近 forearm/upper arm 等非末端连杆，验证全身风险响应 | 是 |
| 场景 C：混合动态接近 | 同一条序列中同时出现末端和中间连杆风险，作为增强验证 | 可选 |

建议至少准备两条录制序列：一条末端附近风险序列，一条中间连杆风险序列。若现有 4.3 动态序列中已经包含这两类帧，可以直接复用，无需重新录制。

## 2. 对比方法

`experiments/exp_44_main.py` 一次运行会同时计算四种方法：

| 方法 | 程序内部名称 | 表面采样范围 | 风险依据 | 复现边界 |
| --- | --- | --- | --- | --- |
| APF | `apf` | 全身表面 | 当前参考障碍物点云 | 经典人工势场思想，使用当前最近距离诱导排斥，不使用未来风险 |
| Ours-EE only | `ours_ee_only` | 末端/夹爪表面 | 当前参考障碍物点云 | 只保护末端，用于说明仅末端避障无法覆盖中间连杆风险 |
| Ours-w/o Temporal | `ours_wo_temporal` | 全身表面 | 当前参考障碍物点云 | 使用全身构型相关距离，但不使用速度外推 |
| Ours | `ours` | 全身表面 | 当前点云 + 速度外推风险点云 | 在 4.3 速度估计基础上构造未来风险占据，增强动态接近响应 |

说明：

- 4.4 关注“排斥向量方向是否合理”，不是完整闭环控制性能。
- 四种方法最终都输出关节空间排斥速度 `dot_q_rep(t)`。
- 为降低实现复杂度和避免依赖控制器，程序使用有限差分计算 `D_ref` 对关节角的梯度，并用归一化梯度构造排斥关节速度。
- `Ours` 会把当前参考障碍物点云按估计速度外推到 `prediction_horizon` 内，形成离线的未来风险点云集合。

## 4. 评价指标

### 4.1 `C_grad_D`：参考距离梯度一致性

对每个排斥激活帧 `t`：

```text
C_t = dot(dot_q_rep, grad_q D_ref) / (||dot_q_rep|| ||grad_q D_ref||)
```

其中 `grad_q D_ref` 由有限差分计算。`C_grad_D` 为所有激活帧的平均值。

| 取值 | 含义 |
| --- | --- |
| 接近 1 | 排斥速度方向与参考距离增大方向高度一致 |
| 大于 0 | 排斥速度整体有助于增大参考距离 |
| 小于 0 | 排斥速度可能把机器人推向更危险构型，需要检查方法或数据 |

### 4.2 `G_rep`：虚拟一步距离增益

对每个排斥激活帧执行虚拟一步：

```text
q_hat = q_t + dot_q_rep(t) * dt_v
G_t = D_ref(q_hat, t) - D_ref(q_t, t)
```

`G_rep` 为所有激活帧的平均值，单位为米。该指标越大，说明排斥速度越能在局部一步内增大风险距离。

### 4.3 `R_body`：非末端连杆风险响应率

先筛选非末端连杆风险事件：

```text
D_body < d_safe 且 D_ee > d_safe
```

也就是障碍物靠近中间连杆，但末端仍然安全。若某方法在该帧生成 `||dot_q_rep|| > eta_th` 的排斥速度，则记为成功响应。`R_body` 越大，说明方法越能保护非末端连杆。

预期上，`Ours-EE only` 在中间连杆风险场景中 `R_body` 应明显较低，理想情况下接近 `0`。

## 5. 实验前准备

### 5.1 进入项目环境

本项目已配置 `py310` conda 环境。4.4 的运行方式与 4.2、4.3 保持一致：先激活环境，再使用 `python -m ...` 运行实验入口。

```bash
conda activate py310
python -m experiments.exp_44_main --help
```

如果出现 `ModuleNotFoundError`，通常说明当前终端没有激活 `py310`。

### 5.2 确认 4.3 录制数据

建议至少准备以下目录：

```text
data/recordings/ch4_3_empty/          # 空场景基线
data/recordings/ch4_3_dynamic_ee/     # 末端附近风险序列
data/recordings/ch4_3_dynamic_body/   # 中间连杆风险序列
```

如果已经有以下类似目录，也可以直接使用：

```text
data/recordings/ch4_3_dynamic_01/
data/recordings/ch4_3_dynamic_02/
data/recordings/ch4_3_recover_01/
```

### 5.3 数据质量快速检查

先播放一条录制序列，确认点云和障碍物可见：

```bash
python -m experiments.play_recording \
  --record-dir data/recordings/ch4_3_dynamic_01 \
  --stride 5
```

如果播放时看不到障碍物，4.4 的 `active_frames` 可能为 0，需要重新选择序列或重新录制。

## 6. 数据录制建议

如果现有 4.3 数据不足，可以按下面方式补录。录制仍然使用 4.3 的 `experiments.exp_43_recorder`。

### 6.1 录制空场景基线

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_empty \
  --scene A \
  --duration 60 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --record-fps 4 \
  --obstacle-desc "empty baseline for 4.4"
```

### 6.2 录制末端附近风险序列

让障碍物主要靠近末端/夹爪附近，保持最近距离约 `0.08-0.12 m`，不要接触机器人：

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_dynamic_ee \
  --scene B \
  --duration 20 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.05 \
  --record-fps 4 \
  --obstacle-desc "object approaching end effector for 4.4"
```

操作要点：

1. 按空格开始录制后，先让障碍物在远处停留 1-2 秒。
2. 缓慢接近末端或夹爪区域。
3. 在安全距离内停留 1-2 秒。
4. 再缓慢远离。

### 6.3 录制中间连杆风险序列

让障碍物靠近 forearm、upper arm 或 wrist1/wrist2 等非末端连杆，末端尽量保持较远：

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_dynamic_body \
  --scene B \
  --duration 20 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.05 \
  --record-fps 4 \
  --obstacle-desc "object approaching middle robot links for 4.4"
```

操作要点：

1. 障碍物从侧方靠近中间连杆，不要跟随末端移动。
2. 保持障碍物与末端距离大于 `d_safe`，这样 `R_body` 的事件定义更清晰。
3. 每条序列控制在 15-25 秒，便于离线有限差分计算。

## 9. 关键参数

| 参数 | 默认值 | 建议调整方式 |
| --- | --- | --- |
| `--delta-r` | `0.05` | 与 4.2/4.3 自滤除阈值保持一致 |
| `--bg-eps` | `0.03` | 空场景背景差分阈值；障碍物被背景吞掉时可减小到 `0.02` |
| `--eps-q` | `1e-4` | 有限差分关节扰动，不建议大幅修改 |
| `--dt-v` | `0.08` | 虚拟一步执行时间；过大可能越过局部线性区域 |
| `--eta-th` | `0.01` | 排斥激活阈值，单位 rad/s |
| `--eta-max` | `0.3` | 最大排斥速度幅值 |
| `--stride` | `3` | 每隔多少帧评价一次；越小越精细但越慢 |
| `--max-frames` | 不限制 | 调试时建议 `80-300`，正式实验可 `900` 或更高 |
| `--mesh-samples` | `50000` | 调试可用 `20000`，正式建议 `50000` |

## 10. 预期结果与论文表述建议

### 10.1 指标预期

| 方法 | `C_grad_D` 预期 | `G_rep` 预期 | `R_body` 预期 |
| --- | --- | --- | --- |
| APF | 大于 0，但可能低于本文方法 | 大于 0，增益有限 | 有响应，但动态接近时不够提前 |
| Ours-EE only | 末端场景大于 0 | 末端场景大于 0 | 中间连杆场景明显偏低或接近 0 |
| Ours-w/o Temporal | 通常大于 APF/EE-only | 大于 0 | 中间连杆场景应明显高于 EE-only |
| Ours | 通常最高或接近最高 | 通常最大 | 中间连杆场景保持较高 |

### 10.2 可接受的结果判断

正式结果中应满足：

1. 四种方法的 `C_grad_D` 大多为正，说明排斥速度没有系统性地指向危险方向。
2. `Ours` 和 `Ours-w/o Temporal` 的 `R_body` 明显高于 `Ours-EE only`。
3. `Ours` 在动态接近序列中的 `G_rep` 不低于 `Ours-w/o Temporal`，体现未来风险占据的增益。
4. `fig44.png` 中，中间连杆风险帧的最近 link 应为非末端 link。

如果 `Ours` 未明显优于 `Ours-w/o Temporal`，可以在论文中如实表述为：4.4 主要验证构型相关排斥方向的正确性，时域预测的优势已在 4.3 的提前预警指标中体现；4.4 的虚拟一步指标只反映局部一阶距离增益。

## 11. 常见问题

### 11.1 `active_frames = 0`

可能原因：

- 障碍物没有进入 `d_safe = 0.15 m`。
- 空场景背景差分把障碍物点云过滤掉。
- 录制序列中点云与机器人 FK 未对齐，导致参考距离异常。

建议：

```bash
python -m experiments.exp_44_main \
  --record-dir data/recordings/ch4_3_dynamic_body \
  --empty-record-dir data/recordings/ch4_3_empty \
  --output data/results/ch4_4_debug \
  --stride 10 \
  --max-frames 120 \
  --bg-eps 0.02 \
  --plot
```

并打开 `trial_00.json` 检查：

- `frame_summary.sampled_frames`
- `frame_summary.ee_risk_frames`
- `frame_summary.body_risk_frames`
- `frame_summary.nearest_links`

### 11.2 `R_body` 为 `-` 或空值

表示该序列没有满足 `D_body < d_safe 且 D_ee > d_safe` 的非末端风险事件。需要重新选择中间连杆风险序列，或补录时让障碍物更明确地靠近中间连杆、远离末端。

### 11.3 运行很慢

4.4 需要对每个激活帧、每个方法、每个关节做有限差分，因此比 4.3 慢是正常的。先用：

```bash
--stride 8 --max-frames 80 --mesh-samples 20000
```

确认结果合理后，再改为：

```bash
--stride 3 --max-frames 900 --mesh-samples 50000
```

### 11.4 图 4-4 只生成一个子图

说明该序列中只找到了末端风险或只找到了中间连杆风险。可以分别对末端序列和中间连杆序列运行 `exp_44_plot.py`，或者使用包含两类风险帧的混合序列。

## 12. 推荐执行顺序

1. 用 4.3 的播放程序检查现有动态序列。
2. 若已有末端风险和中间连杆风险序列，直接进入 4.4；否则按第 6 节补录。
