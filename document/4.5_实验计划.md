# 4.5 风险约束安全运动生成实验 — 实施计划

## 1. 实验目的

验证完整方法能否将时空风险占据、构型相关风险距离和局部排斥向量转化为安全、平滑且可执行的闭环机器人运动。与 4.3/4.4 的离线回放不同，本节**真实机器人在线运行**不同方法，对比安全性和任务完成能力。

### 3.1 `experiments/exp_45_controller.py` — 五种对比方法的控制器

每种方法封装为一个控制器类，统一接口：

```python
class SafeMotionController(ABC):
    """所有对比方法的统一接口"""
    scene_points: np.ndarray           # 外部点云（自滤后）
    tracked_objects: list              # OccupancyObject 列表
    joint_angles: dict                 # 当前关节角
    cmd_joint_velocity: np.ndarray     # 输出的关节速度指令 (6,)

    @abstractmethod
    def step(self, scene_points, tracked_objects, joint_angles, dt) -> np.ndarray:
        """输入当前感知结果+机器人状态，输出安全关节速度指令"""
        pass
```

#### 3.1.1 SSM 控制器

```python
class SSMController(SafeMotionController):
    """基于安全距离阈值进行速度限制或停止
       1. 不生成排斥向量
       2. 用当前帧到障碍物的最近距离 d_min
       3. 若 d_min > d_safe: speed_scale = 1.0
       4. 若 d_stop < d_min <= d_safe: speed_scale = (d_min-d_stop)/(d_safe-d_stop)
       5. 若 d_min <= d_stop: speed_scale = 0.0
       6. 参考速度 × speed_scale 直接输出
    """
    pass
```

#### 3.1.2 APF 控制器

```python
class APFController(SafeMotionController):
    """人工势场局部避障
       1. 计算最近障碍物方向
       2. 排斥力 F_rep = eta * (1/d - 1/d_safe)^2 * direction / d^2
       3. 合力 = 参考运动力 + F_rep
       4. 通过雅可比映射到关节速度
       5. 幅值限制
    """
    pass
```

#### 3.1.3 Ours-Scale 控制器

```python
class OursScaleController(SafeMotionController):

       1. 用 capsule_sphere_distance 计算最小距离
       2. SafetyPolicy.evaluate() 得到 speed_scale
       3. ref_velocity × speed_scale → 输出
       4. 不做排斥向量，不做安全滤波
    """
    pass
```

#### 3.1.4 Ours-Rep 控制器

```python
class OursRepController(SafeMotionController):
    """速度缩放 + 排斥向量，无速度级安全滤波
       1. 计算 speed_scale
       2. 计算排斥关节速度 dot_q_rep（来自全身表面+未来风险占据）
       3. 输出 = speed_scale × ref_velocity + dot_q_rep
       4. 幅值限制 (||output||_inf < joint_velocity_limits)
    """
    pass
```

#### 3.1.5 Ours-Full 控制器

```python
class OursFullController(SafeMotionController):
    """完整方法: 速度缩放 + 排斥向量 + 速度级安全滤波
       1. speed_scale × ref_velocity → 参考速度
       2. 计算排斥向量 dot_q_rep
       3. 候选速度 = 参考速度 + dot_q_rep
       4. 速度级安全滤波：
          a. 对候选速度的每个方向分量，检查是否减小了风险距离
          b. 若某分量增大风险（使机器人更靠近障碍物），则抑制该分量
          c. 解析投影到安全半空间
       5. 输出滤波后的关节速度
    """
    pass
```

## 4. 实验方案

### 4.5.2 场景 A：静态障碍物

| 项目 | 设置 |
|------|------|
| 障碍物 | 纸箱 0.30×0.25×0.20m，放置在桌面 Y 轴行程末端附近 |
| 机器人运动 | Y 轴 ±0.20m 往复，base_speed=0.10 m/s |
| 障碍物位置 | 距离末端最近点约 0.15m（在机器人路径上） |
| 对比方法 | 全部 5 种 |
| 重复次数 | 每种方法 3 次 |
| 关键指标 | D_min^ref, T_viol, R_avoid, ΔT |

### 4.5.2 场景 B：动态障碍物横向进入

| 项目 | 设置 |
|------|------|
| 障碍物 | 手持泡沫棒/轻质纸管 (~1.0m 长) |
| 进入方向 | 从机器人前侧方（X 正方向）横向进入 |
| 机器人运动 | Y 轴 ±0.20m 往复 |
| 对比方法 | 全部 5 种 |
| 重复次数 | 每种方法 5 次（不同进入速度 0.3-0.8 m/s） |
| 关键指标 | D_min^ref, T_viol, R_avoid, R_timeout, ΔT, J_q^rms |

### 4.5.2 场景 C：障碍物靠近中间连杆

| 项目 | 设置 |
|------|------|
| 障碍物 | 纸箱或泡沫块，从机器人侧面靠近 forearm/upper_arm |
| 机器人运动 | Y 轴 ±0.20m 往复 |
| 末端位置 | 确保末端远离障碍物（Y 方向偏移） |
| 对比方法 | SSM, Ours-Scale, Ours-Rep, Ours-Full（APF 可选） |
| 重复次数 | 每种方法 3 次 |
| 关键指标 | D_min^ref, R_avoid, R_body 响应 |

## 5. 实验流程

```
每轮实验：
  1. 机器人回到 Home pose [0,0,90,0,90,0]°
  2. 启动参考运动（Y 轴往复）
  3. 开始记录日志（点云、关节状态、指令、安全状态）
  4. 等待障碍物就位 → 开始障碍物动作
  5. 录制 duration 秒
  6. 停止记录，停止机器人
  7. 离线重处理：计算 P_obs^ref 和 D_ref
  8. 计算评价指标
```

## 8. 安全措施

1. 每次实验前空跑 3s 验证感知+控制管道正常
2. 动态障碍物使用软质材料（泡沫、纸箱）
3. 软件限速：base_speed ≤ 0.10 m/s
4. 硬件急停按钮就绪
5. 操作员站在急停开关旁全程监视
6. 人手直接进入仅做低速展示，不入主表

## 9. 已生成的实验程序与实际使用方法

本节已新增一套**回放优先**的安全运动生成实验程序。当前程序不会直接驱动真实机器人，而是使用录制序列生成各控制方法的关节速度指令日志，并计算 4.5 所需指标。这样可以先验证控制逻辑和评价流程，确认安全后再接入真实机器人执行。

| 文件 | 作用 |
| --- | --- |
| `experiments/exp_45_controller.py` | SSM/APF/Ours-Scale/Ours-Rep/Ours-Full 五种控制器 |
| `experiments/exp_45_runner.py` | 回放录制序列，生成各方法的控制日志 |
| `experiments/exp_45_eval.py` | 计算 `D_min_ref`、`T_viol`、`R_avoid`、`R_timeout`、`J_q_rms` 等指标 |
| `experiments/exp_45_plot.py` | 绘制图 4-5 曲线 |

### 9.0 对比控制器复现说明

4.5 不是只运行 Ours-Full。`exp_45_runner.py` 支持五种控制器，既可以一次运行全部，也可以单独运行某一种。

| 论文方法 | 命令参数 | 复现边界 |
| --- | --- | --- |
| SSM | `--controller ssm` | 只根据当前 `D_ref(t)` 和固定安全阈值缩放参考速度，不生成排斥向量 |
| APF | `--controller apf` | 当前帧人工势场排斥 + 速度缩放，不使用未来风险预测和安全滤波 |
| Ours-Scale | `--controller ours_scale` | 只使用本文风险距离对应的速度缩放，不使用排斥向量 |
| Ours-Rep | `--controller ours_rep` | 速度缩放 + 构型相关排斥向量，不做速度级安全滤波 |
| Ours-Full | `--controller ours_full` | 速度缩放 + 排斥向量 + 速度级安全滤波 |
| 全部控制器 | `--controller all` | 同一条录制序列上依次生成五种控制器日志 |

### 9.5 推荐执行顺序

1. 先用 4.3 的动态接近序列运行 `exp_45_runner`；
2. 检查五种控制器生成的 `cmd_velocity` 是否没有异常尖峰；
3. 用 `exp_45_plot` 画出典型 Ours-Full 曲线；
4. 对多个 trial 重复运行，得到表 4-6 所需均值；
5. 确认回放结果合理后，再考虑把 `exp_45_controller.py` 中的控制器接入真实机器人在线执行流程。

### 9.6 关于真实机器人在线实验

当前新增程序提供的是安全的离线/回放实现。真实机器人在线执行时，应在现有 `robot/safety_guided_motion.py` 或你的机器人控制入口中调用 `exp_45_controller.py` 的控制器逻辑，并保持以下原则：

- 先 mock 模式，再低速空跑，再加入静态障碍物；
- `Ours-Full` 最后测试；
- 保留硬件急停；
- 动态障碍物使用泡沫棒、纸箱等软质物体；
- 不要直接让人手高速进入工作空间。
