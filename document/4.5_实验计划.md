# 4.5 风险约束安全运动生成实验计划与使用步骤

本计划用于完成第四章 4.5 节“风险约束安全运动生成实验”。4.3 已验证对象级时空风险占据能够更早给出预警，4.4 已验证构型相关排斥关节速度总体沿着增大参考风险距离的方向运动。4.5 进一步验证：这些风险信息能否转化为安全、平滑、可执行的机器人运动。

考虑真实机器人闭环实验的风险，本节采用“两阶段”实施：

1. **离线闭环回放阶段**：在 4.3 录制序列上重建 `P_obs^ref(t)` 和 `D_ref(q_t,t)`，用统一参考关节速度模拟五种控制器的在线决策，生成 4.5 日志、表格和图 4-5。该阶段不向真实机械臂发送指令，是论文定量结果的主要来源。
2. **真实机器人演示阶段**：在完成离线验证后，使用 `robot/safety_guided_motion.py` 进行低速安全引导演示，观察真实感知、减速、停止和恢复过程。真实演示主要用于现象验证和视频/截图材料。

---

## 1. 实验总体设计

4.5 的输入为 4.3 已录制的 RGB-D 点云与关节状态序列。每帧先复用 4.3 的离线参考构造得到：

```text
P_obs^ref(t): 外部障碍物参考点云
D_ref(q_t,t): 外部障碍物点云到机器人全身表面的最近距离
```

随后用 4.4 的排斥向量计算器生成构型相关排斥速度，并用 4.5 控制器生成最终关节速度指令：

```text
qdot_cmd(t) = controller(ref_qdot(t), P_obs^ref(t), D_ref(q_t,t), q_t)
```

离线回放只评价控制器“在当时感知和构型下会输出什么速度”，不改变原始录制中的真实关节轨迹。因此，4.5 的 `D_ref` 是统一参考距离，用于比较不同控制策略对同一风险过程的响应差异；真实闭环轨迹差异可作为后续真实机器人演示或补充实验。

## 2. 实验场景

| 场景 | 内容 | 目的 | 是否进入主表 |
| --- | --- | --- | --- |
| 场景 A：静态障碍物 | 纸箱/工具盒放在 Y 轴往复路径附近，但不主动移动 | 评价误停、低速绕行和状态稳定性 | 是 |

| 场景 C：中间连杆风险 | 障碍物靠近 forearm/upper_arm/wrist 等非末端连杆 | 评价全身风险响应能力 | 是 |

## 3. 对比方法

4.5 程序一次可运行五种控制器：

| 方法 | 程序名称 | 速度缩放 | 排斥向量 | 速度级安全滤波 | 说明 |
| --- | --- | --- | --- | --- | --- |
| SSM | `ssm` | 是 | 否 | 否 | 只按当前 `D_ref` 做安全距离缩放 |
| APF | `apf` | 是 | 当前势场排斥 | 否 | 经典人工势场思想，不使用未来风险占据 |
| Ours-Scale | `ours_scale` | 是 | 否 | 否 | 只验证本文风险距离驱动的速度缩放 |
| Ours-Rep | `ours_rep` | 是 | 本文排斥向量 | 否 | 验证排斥向量带来的主动避让效果 |
| Ours-Full | `ours_full` | 是 | 本文排斥向量 | 是 | 完整方法：缩放 + 排斥 + 安全半空间投影 |

五种方法共用同一套 `d_safe/d_slow/d_stop`、同一条录制序列和同一组参考速度，避免数据差异影响比较。

## 5. 评价指标

| 指标 | 含义 | 趋势 |
| --- | --- | --- |
| `D_min_ref` | 全序列最小参考距离 `min_t D_ref(q_t,t)` | 越大越安全 |
| `T_viol` | `D_ref < d_stop` 的累计时间 | 越小越好 |
| `R_avoid` | 满足安全距离、未超时且末端误差合格的 trial 比例 | 越大越好 |
| `R_timeout` | 任务超时比例 | 越小越好 |
| `Delta_T` | 相对无障碍标称时间的任务耗时增加 | 越小越好 |
| `J_q_rms` | 指令关节速度差分 RMS，反映运动平滑性 | 越小越平滑 |

当前离线回放日志没有真实任务终点误差，`E_final` 默认记为 `0`；若后续接入真实闭环轨迹，可在日志中补写 `final_error` 后重新运行 `exp_45_eval.py`。

## 7. 数据录制步骤

若已有 4.3 数据，可跳过本节。若需要补录，仍使用 4.3 的录制入口。

### 7.1 录制空场景基线

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_empty \
  --scene A \
  --duration 60 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --record-fps 4 \
  --obstacle-desc "empty baseline for 4.5"
```

### 7.2 录制场景 A：静态障碍物

1. 将纸箱或工具盒放在机器人 Y 轴往复路径末端附近。
2. 最近距离建议保持 `0.12-0.18 m`，不要接触机器人。
3. 录制时机器人执行同样的 Y 轴往复运动。

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_static_A \
  --scene A \
  --duration 60 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.05 \
  --record-fps 4 \
  --obstacle-desc "static obstacle near Y-axis path for 4.5"
```

### 7.3 录制场景 B：动态横向进入

1. 障碍物先在远处静止 `1-2 s`。
2. 从机器人前侧方横向进入，接近到 `0.06-0.12 m`。
3. 停留约 `1-2 s` 后远离。
4. 重复 `5-8` 条 trial，覆盖慢速、中速、较快进入。

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_dynamic_01 \
  --scene B \
  --duration 20 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.05 \
  --record-fps 4 \
  --obstacle-desc "dynamic lateral obstacle for 4.5"
```

### 7.4 录制场景 C：中间连杆风险

1. 障碍物从侧面靠近 forearm、upper_arm 或 wrist1/wrist2。
2. 尽量让末端远离障碍物，使风险主要来自中间连杆。
3. 每条序列控制在 `15-25 s`，便于后续有限差分计算。

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_dynamic_body \
  --scene C \
  --duration 20 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.05 \
  --record-fps 4 \
  --obstacle-desc "middle-link obstacle for 4.5"
```

## 10. 虚拟闭环积分补充实验

普通离线回放不改变原始机器人轨迹，因此不同控制器的 `D_min_ref` 和 `T_viol` 相同。为进一步验证本文方法是否能够在闭环运动层面增大安全距离，本节补充虚拟闭环积分实验：

```text
q_sim(t+1) = q_sim(t) + qdot_cmd(t) * dt
D_ref(t+1) = distance(P_obs^ref(t+1), S_R(q_sim(t+1)))
```

该实验仍不向真实机器人发送指令，但会让不同方法产生不同的模拟机器人轨迹，因此可直接比较 `D_min_ref`、`T_viol` 和 `R_avoid`。

## 12. 真实机器人演示步骤

真实演示建议只运行完整安全引导逻辑，并保持低速、轻质障碍物和人工急停可用。

### 12.1 空场景检查

```bash
python robot/safety_guided_motion.py \
  --real-robot \
  --visualize \
  --remove-planes \
  --range 0.20 \
  --motion-x-offset -0.05
```

确认：

1. 机器人 Y 轴往复范围正确；
2. 可视化中机器人点云和障碍物点云坐标一致；
3. 无障碍物时 `speed_scale` 接近 `1.0`；
4. 停止程序后机器人能平稳停止。

### 12.2 静态障碍演示

1. 将纸箱放到路径附近，初始距离大于 `d_stop`。
2. 启动程序并观察机器人是否在接近障碍物时减速。
3. 移开障碍物后观察速度是否恢复。

### 12.3 动态障碍演示

1. 使用泡沫棒或轻质纸管，从侧方缓慢进入。
2. 先以低速接近，确认减速/停止逻辑正常。
3. 再做 2-3 次不同速度接近，记录视频或截图。

真实演示只作为补充材料，不建议用它替代离线回放统计。若要进行真实闭环定量，需要额外保存真实执行后的 `q_t`、`qdot_cmd` 和点云日志，再用 `experiments.exp_45_eval` 重新计算指标。

## 13. 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `obs_count` 长期为 0 | 空场景差分过强、障碍物不在 ROI、点云被机器人邻域剔除 | 调小 `--bg-eps` 或检查 `workspace.yaml` |
| 五种方法结果几乎一致 | 序列没有进入 `d_safe`，排斥向量未激活 | 更换更近的动态障碍 trial |
| `Ours-Rep` 抖动大 | 排斥向量未经过速度级滤波，且风险点云抖动 | 论文中作为无滤波消融现象讨论 |
| `Ours-Full` 指令过小 | 安全半空间投影抑制了靠近风险方向的速度 | 检查 `D_ref` 曲线，确认是否确实处于危险区 |
| 回放计算慢 | 4.4 有限差分需要多次 FK 和距离查询 | 调试时使用 `--max-frames`，正式统计再跑全量 |

## 14. 推荐论文表述

4.5 可以按以下逻辑撰写：

1. 先说明实验承接 4.3 的时空风险占据和 4.4 的构型相关排斥向量。
2. 再说明五种方法的区别：SSM/APF 为基线，Ours-Scale/Ours-Rep/Ours-Full 为逐步加入模块。
3. 定量表突出 `D_min_ref`、`T_viol`、`R_avoid` 和 `J_q_rms`。
4. 图 4-5 展示完整方法在动态接近时的风险距离、速度缩放和排斥速度响应。
5. 讨论中强调：速度缩放保证保守安全，排斥向量提升主动避让能力，速度级安全滤波抑制可能降低风险距离的速度分量，从而在安全性和平滑性之间取得平衡。
