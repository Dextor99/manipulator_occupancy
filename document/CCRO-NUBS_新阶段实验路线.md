> 用途：汇总 CCRO-NUBS 当前程序、实验效果、论文证据链缺口和后续实施顺序，作为后续开发、实验、验收与论文写作的统一参考。

> 关联文档：`CCRO-NUBS_论文框架与实现路线.md`、`CCRO-NUBS_实现方案.md`、阶段 1–4 实施计划。

## 1. 当前总体判断

目前已经打通论文方法的核心程序链：

```text
RGB-D/录制数据
  -> 机器人自身点云解耦
  -> 对象跟踪与短时预测
  -> URDF/Mesh 全身构型风险
  -> NUBS 连续轨迹优化
  -> 动态时空风险
  -> 风险触发异步重规划
  -> 候选轨迹复核/安全保持
```

当前状态不能简单概括为“全部完成”，应按能力层次区分：

| 层次 | 当前状态 | 判断 |
|---|---|---|
| 方法核心链路 | 阶段 1–4 已贯通 | 基本完成 |
| 程序化实验 | 阶段 1–4 均 `accepted=true` | 已完成首轮验证 |
| 自动测试 | 阶段 1–4 共 `19 passed` | 基础回归可用 |
| 真实录制证据 | 4.2–4.6 已有数据，但尚未完整进入 NUBS 重规划闭环 | 部分完成 |
| 统计充分性 | 阶段 2–4 场景数和随机重复不足 | 未完成 |
| 端到端实时性 | 控制和规划均有明确瓶颈，感知耗时埋点不完整 | 未达到 |
| 真机轨迹切换 | 缺少执行器、自碰撞、watchdog 等 | 禁止开启 |

推荐的总体表述：

> CCRO-NUBS 的算法主体已经完成，程序化静态、动态风险优化和异步重规划验证均通过；当前工作重点应从继续增加孤立功能，转向补齐真实数据证据、统一消融、统计重复实验、实时性优化和分阶段真机验证。

## 2. 论文创新点与完成情况

### 2.1 创新点 1：构型耦合全身风险建模

已完成能力：

- 从 AUBO-i16 URDF collision Mesh 加载全身几何；
- 确定性 coarse/medium/dense 多分辨率表面采样；
- FK 将局部表面点变换到当前构型；
- 等连杆权重的全身风险聚合；
- 最近风险连杆识别；
- 末端安全但前臂/腕部危险的反例；
- 静态点云和动态球占据的统一距离查询。

已有真实录制数据证据：

```text
无障碍机器人邻域残留比例 R_res    0.0629
无障碍误触发率 R_false             0.0027
自身点云解耦平均耗时                约 6.50 ms
单障碍 R_keep                       1.0000
单障碍 R_det                        1.0000
单障碍解耦耗时                      约 6.29 ms
```

当前缺口：

- Mesh 采样密度误差—耗时关系尚未与 CCRO-NUBS 主实验统一；
- 缺少正式胶囊体/简化连杆模型对比；
- 尚未加入自碰撞检查；
- 真实障碍物三维中心真值不完整。

阶段判断：构型耦合全身风险主体完成，真实几何精度和系统安全边界待补。

### 2.2 创新点 2：全身风险驱动的 NUBS 轨迹优化

该部分的固定时间算法主体已经完成。

#### 阶段 1：NUBS 后端

结果：

```text
边界 q/qd/qdd                 全部通过
中间构型误差                  2.29e-16
梯度相对误差                  3.67e-11
初始 jerk 能量                1.010818
最终 jerk 能量                0.070139
jerk 能量下降                 约 93.1%
关节位置/速度/加速度超限      0
单次优化耗时                  约 12.35 ms
101 点轨迹采样平均耗时         约 0.121 ms
```

结论：NUBS 数学后端稳定，可作为论文轨迹表示和梯度传播核心。

待补：

- 多组随机起终构型统计；
- 与五次多项式、MINCO 的正式对比；
- 总时长及分段时间优化。

#### 阶段 2：静态全身风险

A/B/C 三组程序化实验均通过。

| 场景 | 无风险/基线 | 仅末端 | 全身 Mesh |
|---|---:|---:|---:|
| A 末端附近障碍 | 失败 | `D_min=0.08130 m`，通过 | `D_min=0.10647 m`，通过 |
| B 身体连杆障碍 | 失败 | `D_min≈0.00044 m`，失败 | `D_min=0.10162 m`，通过 |
| C 多障碍 | 失败 | `D_min=0.05437 m`，通过 | `D_min=0.10294 m`，通过 |

完整目标梯度相对误差：

```text
0.00301
```

关键结论：

- 无风险 NUBS 只能保证连续和平滑，不能保证避障；
- 仅末端风险会遗漏前臂/上臂等身体风险；
- 全身 Mesh 风险能够进入 NUBS 优化并通过 dense 复核。

待补：

- 多随机种子统计；
- 静态录制点云直接进入 NUBS 优化；
- RRT-Connect 等统一几何基线；
- 固定时间与可优化时间对比；
- 规划成功率、p95、超时率和复核拒绝率。

### 2.3 创新点 3：动态时空风险与分层重规划

#### 阶段 3：动态时空风险

全身时空法结果：

| 场景 | 当前帧全身 | 仅末端时空 | 全身时空 |
|---|---:|---:|---:|
| A | 失败，`D_min=0` | 通过，`0.11423 m` | 通过，`0.11378 m` |
| B | 失败，`D_min=0` | 失败，`D_min=0` | 通过，`0.09773 m` |
| C | 失败，`D_min=0` | 失败，`0.01289 m` | 通过，`0.09244 m` |

时空目标梯度：

```text
relative_error      1.41e-6
cosine_similarity   约 1.0
```

录制动态预警辅助结果：

```text
时空预测 T_lead      5.1286 s
当前帧 T_lead        4.7356 s
提前量增益           +0.3929 s
```

结论：

- 当前帧占据不足以处理未来动态穿越；
- 仅末端时空风险仍会遗漏身体碰撞；
- 全身时空风险与轨迹物理时间对齐后能够引导 NUBS 规避动态风险。

待补：

- 录制序列缺少稳定三维中心真值，无法报告位置预测 RMSE；
- 程序化长时匀速真值不等于在线 `0.4 s` 有效预测；
- 需要验证突然变速、停止、反向和预测失配。

#### 阶段 4：异步风险触发重规划

最终程序化结果 `accepted=true`。

| 场景 | passive D_min | active D_min | 结果 |
|---|---:|---:|---|
| A 动态身体 | 0.04984 m | 0.06174 m | 一次重规划接受并到达目标 |
| B 远障碍 | 1.08211 m | 1.08214 m | 正确保持 LOW，不误触发 |
| C 动态末端 | 0.04253 m | 0.08276 m | 一次重规划接受并到达目标 |
| D 当前碰撞 | 0 | 安全保持 | LOW 直接 HIGH，只记录一次接管 |

已经实现：

- 独立进程优化；
- 全局预测时间与候选局部时间对齐；
- 预计切换时刻的非零 `q/qd/qdd` 延迟补偿；
- 正确 warm-start；
- 3 秒硬超时；
- dense 候选复核；
- 当前风险 HIGH 时终止规划并保持；
- 控制循环不被 L-BFGS-B 阻塞。

耗时：

```text
accepted replans     2
mean                 1460 ms
p95                  1502 ms
max                  1507 ms
hard budget          3000 ms
```

当前约为 `0.67 Hz`，不能宣称达到约 `1 Hz` 的规划目标。样本数只有 2，当前耗时仅是功能性证据。

## 3. 高频安全控制现状

已有 10 条虚拟闭环试验，合并场景结果：

| 方法 | D_min_ref | T_viol | R_avoid | J_q_rms |
|---|---:|---:|---:|---:|
| SSM | 0.0561 m | 0.4317 s | 0.5 | 0.2152 |
| APF | 0.0798 m | 0.0225 s | 0.9 | 0.2296 |
| Ours-Rep | 0.1041 m | 0 | 1.0 | 0.3715 |
| Ours-Full | 0.1968 m | 0 | 1.0 | 0.4109 |

已有结论：

- 单纯速度缩放不足；
- 构型相关排斥对中间连杆风险有效；
- 安全过滤能够进一步增大距离；
- 更强主动避让会增加关节速度变化。

但需要明确：

```text
低频异步重规划：已单独验证
高频速度安全层：已单独验证
二者处于同一个 q_sim 虚拟闭环：尚未完成
```

## 4. 当前证据链缺口

### 4.1 统计样本不足

阶段 2–4 主要是固定种子程序化场景，缺少：

- 每类 20–30 次随机场景；
- 成功率和置信区间；
- mean/p95/max；
- 优化超时率；
- 候选复核拒绝率；
- 障碍速度、尺寸、数量和间隙的退化曲线。

### 4.2 时间变量尚未开放

当前所有 CCRO-NUBS 轨迹优化固定 `T`。尚未实现：

```text
P_inner + total_duration
P_inner + segment_durations
```

因此目前只能宣称固定时间连续轨迹优化。

### 4.3 真实动态序列未进入重规划闭环

已有录制数据支持预警和安全控制，但尚未完整形成：

```text
录制障碍序列
  -> 全局时间预测
  -> ReplanManager
  -> 候选 NUBS
  -> dense 复核
  -> 假定切换/安全接管
```

### 4.4 缺少统一 A1–A6 消融

当前结果分散在多个实验目录，需统一：

```text
A1 无风险 NUBS
A2 当前帧全身风险
A3 仅末端时空风险
A4 全身时空风险，不重规划
A5 全身时空风险 + 异步重规划
A6 异步重规划 + 高频速度安全层
```

### 4.5 实时性未达到目标

当前证据：

```text
控制生成平均       40.9 ms
控制生成 p95       199.9 ms
重规划 p95         1502 ms
完整感知耗时       未完整埋点
```

当前不能宣称：

- 高频控制稳定达到 50 Hz；
- 重规划达到 1 Hz；
- 感知到控制端到端实时。

### 4.6 真机执行基础不足

缺少：

- 时间标记关节轨迹执行器；
- 自碰撞检查；
- watchdog；
- 通信中断停止；
- 实际状态与预测切换状态偏差检查；
- 低速真机候选切换验收。

### P2：阶段 2B 时间变量优化

优先级：高  
预计：4–7 天

第一步只开放总时长：

```text
T_i = alpha * T_i_initial
优化变量 = [P_inner, log(alpha)]
```

第二步开放分段时间：

```text
T_i = T_min + softplus(z_i)
```

或者固定总时长下：

```text
T_i = T_total * softmax(z)_i
```

完整目标：

```text
J = lambda_smooth J_jerk
  + lambda_risk J_risk
  + lambda_time T_total
  + J_limits
```

验收：

```text
完整目标梯度相对误差 < 5e-2
所有 T_i >= T_min
dense 复核通过
相同安全门槛下任务时间或 jerk 有可解释改善
```

如果收益不显著，应将时间优化作为扩展或消融，不强行包装为核心贡献。

### P4：统一 A4/A5/A6 虚拟闭环

优先级：最高  
预计：5–7 天

目标架构：

```text
ReplanManager
  -> q_ref, qd_ref
OursFullController
  -> qd_cmd
虚拟执行器 q_sim += qd_cmd * dt
  -> 使用 q_sim 重新计算全身风险
```

对比：

```text
A4 全身时空风险，单次规划
A5 A4 + 异步重规划
A6 A5 + 速度缩放/排斥/安全过滤
```

关键要求：

- 规划期间安全控制继续运行；
- 候选边界使用预计切换状态；
- 切换前使用实际 `q_sim/qd_sim` 再复核；
- 实际状态偏差超过阈值时拒绝候选；
- HIGH、超时和拒绝时实际执行零速/制动，而不是只记日志。

验收：

```text
A6 到达率不低于 A5
A6 的 D_min 和 T_viol 优于 A4/A5
规划期间控制周期无阻塞
候选切换 q/qd 连续
失败场景安全停止
```

该工作包是论文创新点 3 最关键的待完成实验。

### P5：实时性优化

优先级：高  
预计：5–10 天

优化顺序：

1. 只对活跃风险时间窗计算梯度；
2. 只扰动影响最近风险连杆的关节；
3. 缓存 `dq(t)/dP_inner`；
4. 批量化球/点云距离查询；
5. 使用连杆点 Jacobian 计算半解析 `dR/dq`；
6. coarse 优化、medium 中间检查、dense 最终接受；
7. 避免控制周期重复生成完整全身点云；
8. 将热点有限差分从 Python 循环迁移到 NumPy/C++。

阶段目标：

```text
第一目标：重规划 p95 < 1000 ms
增强目标：重规划 p95 < 500 ms
控制生成 p95 < 50 ms
最终控制目标 p95 < 20 ms
```

实时性统计必须至少运行 30 次，报告 mean/p95/max 和超时率。

### P6：统一基线与消融

### P7：真实机械臂分阶段验证

| 周期 | 主要内容 | 关键输出 |
|---|---|---|
| 第 1 周 | P0 + P1 第一批统计 | 可重复基线、随机场景结果 |

## 8. 论文最低成立节点

在不做真机自动候选切换的情况下，建议至少补齐：

1. 阶段 2–4 多随机种子统计；
2. 录制动态序列影子重规划；
3. A4/A5/A6 同一虚拟闭环；
4. 完整耗时埋点和失败率统计。

完成后可以合理支撑：

> 构型耦合时空风险已经进入 NUBS 连续轨迹优化，并能通过事件触发的异步候选轨迹更新与独立安全保护，在动态环境的程序化及录制序列中提高机械臂全身安全距离。

当前及上述最低节点完成前均不应写成：

> 系统已经实现高频、实时、真实机械臂动态在线重规划。
