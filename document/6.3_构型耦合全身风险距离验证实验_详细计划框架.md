## 6.3 小节定位

6.3 用于证明本文“构型耦合全身风险距离”的必要性和有效性。它承接 6.2 的外部障碍占据输入，回答以下问题：

```text
1. 只看末端距离是否会漏掉中间连杆风险；
2. 全身 URDF/Mesh 表面距离能否发现最近风险连杆；
3. 当前帧全身距离能否发现静态近场风险；
4. 对动态障碍，时空风险距离是否能发现未来风险；
5. 真实 RGB-D 回放中，最近风险连杆是否确实会出现在 upperArm、wrist1 等非末端连杆。
```

建议分成两个实验：

```text
6.3.1 仿真构型风险距离对比实验
6.3.2 真实机械臂近场全身风险距离实验
```

## 6.3.1 仿真构型风险距离对比实验

### 1. 实验目的

在可控仿真条件下比较三种风险距离：

| 方法 | 程序名称 | 风险作用对象 | 时间信息 | 证明点 |
|---|---|---|---|---|
| 末端距离 | `eef_only` | 末端/夹爪表面 | 当前帧 | 会漏掉中间连杆风险 |
| 当前帧全身距离 | `body_current` | URDF/Mesh 全身表面 | 当前帧 | 能发现静态全身近场风险 |
| 本文构型耦合时空风险 | `ours_ccro` | URDF/Mesh 全身表面 | 当前 + 未来预测 | 能发现未来动态风险 |

### 2. 仿真场景

程序内置三类场景：

| 场景 | 程序名称 | 作用 | 预期结果 |
|---|---|---|---|
| 末端附近障碍 | `ee_near` | 障碍靠近 wrist/夹爪 | 三种方法均能检出 |
| 身体连杆附近障碍 | `body_near` | 障碍靠近 upperArm/foreArm/wrist1/wrist2 | `eef_only` 漏检，两个全身方法检出 |
| 动态未来穿越 | `dynamic_future` | 当前距离安全，但未来会靠近身体连杆 | `body_current` 漏掉未来风险，`ours_ccro` 检出 |

仿真使用项目真实 URDF/Mesh 表面模型：

```text
URDF：urdf/aubo_i16_gripper.urdf
关节顺序：config/ccro_stage2.yaml 中 robot.joint_names
表面采样：planning.robot_surface_model.RobotSurfaceModel
距离评价：机器人表面点云与障碍物点云 KD-tree 最近距离
```

### 3. 评价指标

| 指标 | 含义 | 趋势 |
|---|---|---|
| `R_detect` | 对真实风险事件的检出率 | 越高越好 |
| `R_body` | 对“身体连杆危险但末端安全”事件的检出率 | 越高越好 |
| `R_future` | 对“当前安全但未来危险”事件的检出率 | 越高越好 |
| `R_false` | 无真实风险时误触发比例 | 越低越好 |
| `D_mean` | 方法报告的平均最近风险距离 | 用于解释保守程度 |
| `D_min` | 方法报告的最小风险距离 | 用于说明最近风险 |
| `T_ms` | 单次距离评价平均耗时 | 越低越好 |

事件定义：

```text
body-only event:
    D_body_current < d_safe 且 D_ee > d_safe

future-only event:
    D_body_current > d_safe 且 D_future < d_safe

true risk event:
    D_future < d_safe
```

### 6. 当前仿真结果

当前已运行默认 `30` 次统计，结果保存在：

```text
data/results/ch6_3_sim/table_6_3_sim.md
```

核心结果：

| 场景 | 方法 | `R_detect` | `R_body` | `R_future` |
|---|---|---:|---:|---:|
| `ee_near` | EEF-only | `1.0000` | - | - |
| `ee_near` | Body-current | `1.0000` | - | - |
| `ee_near` | Ours-CCRO | `1.0000` | - | - |
| `body_near` | EEF-only | `0.4000` | `0.0000` | - |
| `body_near` | Body-current | `1.0000` | `1.0000` | - |
| `body_near` | Ours-CCRO | `1.0000` | `1.0000` | - |
| `dynamic_future` | EEF-only | `0.0333` | `0.0000` | `0.0000` |
| `dynamic_future` | Body-current | `0.4000` | `1.0000` | `0.0000` |
| `dynamic_future` | Ours-CCRO | `1.0000` | `1.0000` | `1.0000` |

论文可写结论：

```text
1. 在末端附近障碍场景中，末端距离与全身距离均能发现风险；
2. 在身体连杆近场场景中，末端距离对 body-only 事件完全漏检，而全身方法能够稳定检出；
3. 在动态未来穿越场景中，当前帧全身距离无法检出 future-only 事件，而 Ours-CCRO 通过未来风险占据实现全部检出；
4. 因此，全身几何和时空预测分别对应“空间覆盖”和“时间提前”两个必要因素。
```

注意事项：

```text
Ours-CCRO 的耗时高于当前帧方法，因为它评价了多步未来风险点云。
论文中应将该结果解释为时空风险带来的计算开销，并在 6.7 实时性分析中讨论优化空间。
```

## 6.3.2 真实机械臂近场全身风险距离实验

### 1. 实验目的

在真实 RGB-D 回放和真实机械臂关节状态下验证：

```text
1. 最近风险连杆并不总是末端；
```

### 5. 真实实验补录步骤

如果后续需要新增真实 6.3 数据，可按以下步骤采集。

#### 5.1 末端近场风险

```text
1. 固定 RealSense 外部视角；
2. 机器人执行低速往复参考运动；
3. 实验人员手持软质障碍物靠近夹爪或 wrist3 区域；
4. 保持最近距离约 0.08-0.12 m；
5. 保存 RGB-D 点云、关节角和时间戳；
6. 回放计算 D_ee、D_min、nearest_link。
```

#### 5.2 中间连杆近场风险

```text
1. 障碍物从机器人侧方靠近 upperArm、foreArm、wrist1 或 wrist2；
2. 末端尽量保持在 d_safe 外；
3. 每条 trial 录制 15-25 s；
4. 重点检查 body-risk frames 是否大于 0；
5. 若最近连杆仍总是 gripper/left/right，则需要调整障碍物进入位置。
```
