# 第六章实验实现框架方案（仿真—真实融合完整版）

## 0. 总体定位

第六章实验不应只是罗列已有结果，而应围绕论文提出的 **CCRO-NUBS：构型耦合时空风险占据约束非均匀 B 样条轨迹优化方法** 建立完整证据链。实验体系采用 **仿真实验 + 软件回放 + 虚拟闭环 + 真实机械臂闭环** 相结合的方式。

总体分工如下：

```text
仿真实验：用于可控对比、统计验证、NUBS/MINCO/RRT 等轨迹规划方法比较、消融分析；
软件回放：用于复用已有 RGB-D 点云或日志，验证环境占据、自滤除、对象跟踪与风险预警；
虚拟闭环：用于验证动态障碍下的安全响应、轨迹调整、重规划和候选轨迹验收逻辑；
真实实验：用于验证真实 RGB-D 感知、机械臂状态反馈、全身风险距离、动态安全响应和 NUBS 在线重规划实机闭环。
```

第六章最终要证明：

```text
1. 环境占据感知可靠，能够剔除机械臂自身点云并保留外部障碍；
2. 对象级时空风险能比当前帧静态距离更早响应动态障碍；
3. 构型耦合全身风险能发现末端距离方法遗漏的本体连杆风险；
4. 风险约束 NUBS 能生成安全、平滑、可执行轨迹；
5. 与常用方法相比，CCRO-NUBS 在全身安全、动态适应和轨迹连续性方面更有优势；
6. 真实系统中可以形成“感知—风险—NUBS 重规划—候选验收—实机执行”的完整闭环。
```

```text

动态闭环：逐帧更新障碍物状态，计算风险并触发重规划；
输出：轨迹、D_min 曲线、J_risk、重规划次数、候选验收结果。
```

### 真实机械臂平台

```text
机械臂：AUBO i16；

安全：低速、小范围、轻质障碍物、急停按钮、候选轨迹验收、规划超时保护。
```

## 6.1.2 对比方法

### 环境占据感知对比

| 方法 | 简称 | 说明 | 对比目的 |
|---|---|---|---|
| 当前帧点云聚类 | Current Clustering | 只对当前帧外部点云聚类 | 验证无时序预测时动态预警不足 |
| 体素占据 | Voxel Occupancy | 将外部点云离散为体素 | 验证离散占据表达的局限 |
| 八叉树占据地图 | OctoMap | 经典三维概率占据图，可选 | 验证传统占据地图在动态障碍下的残留问题 |
| 本文对象级时空风险 | Ours-STRO | 聚类、跟踪、速度估计、风险膨胀 | 验证对象级时空风险提前预警能力 |

### 构型风险距离对比

| 方法 | 简称 | 说明 |
|---|---|---|
| 末端距离 | EEF-only | 只计算末端到障碍物距离 |
| 当前帧全身距离 | Body-current | 使用机械臂全身 Mesh 表面采样点计算当前帧距离 |
| 本文构型耦合时空风险 | Ours-CCRO | 全身风险 + 动态预测 + 风险膨胀 |

### 轨迹规划对比

| 方法 | 简称 | 说明 |
|---|---|---|
| RRT-Connect + smoothing | RRT-Connect | 经典采样式路径规划，后接时间参数化和平滑 |
| MINCO-base | MINCO-base | 最小控制量多项式轨迹，不加入本文风险项 |
| MINCO-risk | MINCO-risk | MINCO 表示 + 与本文相同 J_risk 采样代价 |
| NUBS-base | NUBS-base | NUBS 表示，但不加入构型耦合风险 |
| 本文方法 | CCRO-NUBS | NUBS + 构型耦合时空风险 + 候选验收 + 滚动重规划 |

### 动态闭环对比

| 方法 | 简称 | 说明 |
|---|---|---|
| 距离缩放 | SSM / Scaling | 根据 D_min 调整速度，不改变轨迹 |
| 人工势场 | APF | 根据障碍物产生局部排斥 |
| 静态 NUBS | Static NUBS | 初始规划一次，不在线重规划 |
| 本文动态重规划 | CCRO-NUBS Replanning | 风险触发局部重规划和候选验收 |

# 6.8 结果讨论与方法局限

## 6.8.1 结果讨论

```text
1. 环境占据实验表明，对象级时空风险占据能够为动态障碍提供结构化输入；
2. 构型风险实验表明，全身风险距离能够检测末端方法遗漏的连杆风险；
3. 轨迹规划实验表明，CCRO-NUBS 能在保持轨迹连续和平滑的同时提高全身最小安全距离；
4. 动态闭环实验表明，风险触发重规划和候选轨迹验收能够提高动态环境安全性；
5. 真实实验表明，所提方法能够在真实 RGB-D 感知和真实机械臂执行条件下形成安全闭环；
6. 真实 NUBS 在线重规划实验进一步验证了方法的系统集成可行性。
```

## 6.8.2 方法局限

```text
1. 当前动态障碍预测采用短时匀速模型，对复杂非线性运动仍有局限；
2. Mesh 表面点云距离计算在高采样密度下耗时较高；
3. NUBS 在线重规划在真实系统中适合触发式低频执行，而非每帧高频优化；
4. 真实实验中深度噪声、遮挡和外参误差可能导致风险估计保守；
5. 后续可引入解析距离梯度、对象级几何距离、GPU 并行和更高层动态预测模型。
```
