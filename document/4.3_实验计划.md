# 4.3 对象级时空风险占据预警实验计划与使用步骤

本计划用于完成第四章 4.3 节“对象级时空风险占据预警实验”。实验目标是验证：在 4.2 已经完成机器人自身点云解耦的基础上，本文方法能否通过对象级跟踪、速度估计和未来风险占据预测，比只看当前帧距离的方法更早、更稳定地给出预警。

本节程序复用 4.2 已有的 `experiments/recorder.py`、`experiments/decoupling_eval.py` 和 `RobotPointRemover`，不修改 4.2 实验程序。4.3 新增或使用的程序集中在 `experiments/` 目录下。

---

## 1. 实验总体设计

4.3 的核心输入是一组离线录制序列：机器人执行相同参考运动，外部障碍物按不同方式接近、停留或离开。所有方法在同一条录制序列上回放，统一使用 4.2 的 Ours 解耦得到外部点云，再进行对象聚类、跟踪和风险判断。

| 场景 | 用途 | 是否进入主定量表 |
| --- | --- | --- |
| 场景 A：静态障碍物误警补充 | 评价无危险接近时的误警率和状态抖动 | 是 |
| 场景 B：动态障碍物接近机器人 | 评价提前预警时间、漏警率和速度敏感性 | 是，核心场景 |
| 场景 C：靠近-停留-远离 | 评价风险解除后的恢复时间和状态切换次数 | 是 |

4.3 的离线参考真值为 `D_ref(t)`：每帧外部障碍物参考点云到机器人表面点云的最近距离。`D_ref(t)` 只用于离线评价，不参与在线风险判断。

---

## 2. 对比方法

| 方法 | 程序内部名称 | 实现边界 |
| --- | --- | --- |
| DSA | `dsa` | 当前帧外部点云到机器人表面最近距离触发，不使用对象跟踪预测 |
| SSM | `ssm` | 当前对象占据到机器人表面距离 + 固定 `d_safe/d_stop` 阈值 |
| Ours-w/o Temporal | `ours_wo_temporal` | 使用本文解耦、聚类和跟踪，但只评价当前对象占据，不构造未来风险占据 |
| Ours | `ours` | 使用对象速度估计、`predict_risk_spheres()` 和未来时空风险占据 |

所有方法共用：

- 同一条录制序列；
- 同一个空场景基线；
- 同一个 4.2 Ours 自滤除结果；
- 同一套 `d_safe/d_slow/d_stop/T_req` 评价标准。

### 3.2 数据目录约定

建议使用以下目录：

```text
data/recordings/ch4_3_empty/          # 空场景基线
data/recordings/ch4_3_empty_static/   # 静止机器人空场景基线，用于场景 C 恢复实验
data/recordings/ch4_3_static_A/       # 场景 A：静态障碍物误警

data/results/ch4_3/                   # 指标、参考距离和图
```

每条录制序列结构由 4.2 的 `recorder.py` 生成：

```text
record_dir/
  manifest.json
  frames/
    frame_00000.npz
    frame_00001.npz
    ...
```

每帧至少包含：

- `points_cam`：相机坐标系点云；
- `joint_values`：机器人关节角；
- `timestamp`：时间戳；
- `manifest.json/joint_names`：关节名顺序。

## 4. 评价指标

| 指标 | 含义 |
| --- | --- |
| `T_lead` | 提前预警时间，`T_lead = t_danger - t_warn`，越大越好 |
| `R_miss` | 漏警率；若 `t_warn > t_danger - T_req` 或未触发，则计为漏警，越小越好 |
| `R_false_time` | 当 `D_ref(t) > d_safe` 时仍非 SAFE 的帧比例，越小越好 |
| `D_trigger_ref` | 方法首次触发时的参考距离 `D_ref(t_warn)`，用于观察触发距离是否随速度提前 |
| `T_recover` | 障碍物离开危险区后恢复到 SAFE 的时间，越小越好 |
| `N_switch` | 状态切换次数，越小越稳定 |

若某条序列没有进入危险区，即不存在 `t_danger`，则 `T_lead` 和 `R_miss` 记为不适用，重点观察 `R_false_time` 和 `N_switch`。

## 6. 数据录制流程

### 6.1 参考运动

4.3 推荐机器人执行与 `robot/safety_guided_motion.py` 一致的 Y 轴往复参考运动：

- Y 轴往复幅值：约 `±0.20 m`；
- 速度：低速、平滑，避免实验人员靠近时出现过大危险；
- 每条测试序列保持同一参考运动，便于与空场景基线做背景差分。

真实设备上可以先运行安全引导运动程序观察运动范围：

```bash
python robot/safety_guided_motion.py \
  --real-robot \
  --visualize \
  --remove-planes
```

正式录制推荐使用 `experiments.exp_43_recorder`。该程序会先连接相机和机器人，准备完成后等待空格键；按下空格后，机器人自动启动 Y 轴往返运动，同时开始保存点云和关节角。这样不需要同时开两个终端。

如果只想录制而不控制机器人，可去掉 `--auto-y-motion`；如果想跳过空格等待，可加 `--no-wait`。

如果录制 90 秒左右，建议加 `--record-fps 4`，这样大约保存 `90 × 4 = 360` 帧，接近 350 帧目标，避免 30 FPS 全量保存导致磁盘和回放压力过大。

如果归位后的初始 TCP X 过大，需要把机器人整体往 X 负方向挪近一些，可加 `--motion-x-offset -0.05` 或 `--motion-x-offset -0.10`。该偏移在启动 Y 轴往返前执行，随后机器人会在新的 X 中心上做 Y 轴往返。建议先从 `-0.05 m` 开始试，确认不会接近桌面、相机支架或障碍物后再增大。

### 6.2 录制空场景基线

空场景基线用于构造背景差分参考。机器人执行同样 Y 轴往复运动，但不要放置动态障碍物。

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_empty \
  --scene A \
  --duration 90 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset 0.00 \
  --obstacle-desc "empty baseline for 4.3 background differencing"
```

如果场景 C 采用机器人静止、只移动障碍物的方式录制，则需要额外录制一组静止机器人空场景基线，避免运动空场景把靠近障碍物误当作背景：

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_empty_static \
  --scene A \
  --duration 20 \
  --source realsense \
  --real-robot \
  --record-fps 4 \
  --obstacle-desc "empty static robot baseline for recover"
```

### 6.3 录制场景 A：静态障碍物误警

放置一个静态纸箱或工具盒，最近点距离机器人约 `0.25-0.35 m`，不要进入危险区。主要用于评价误警率。

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_static_A \
  --scene A \
  --duration 90 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.1 \
  --obstacle-desc "static object outside danger zone"
```

### 6.4 录制场景 B：动态障碍物接近

实验人员手持泡沫棒、纸箱或轻质物体，从侧方进入相机视野并接近机器人：

1. 障碍物在远处；
2. 以自然速度接近；
3. 在机器人表面约 `0.08-0.12 m` 处停止；
4. 保持约 `2 s`；
5. 远离。

建议重复 `5-8` 次，每次单独保存一个 trial：

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_dynamic_01 \
  --scene B \
  --duration 15 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.05 \
  --record-fps 4 \
  --obstacle-desc "hand-held foam object approaching robot"
```

后续可按离线 `speed_median` 将 trial 分为低速、中速、高速组。

### 6.5 录制场景 C：靠近-停留-远离

障碍物接近到约 `0.08 m`，停留 `3 s`，再远离到 `0.30 m` 外。建议重复 `3-5` 次。

```bash
python -m experiments.exp_43_recorder \
  --output data/recordings/ch4_3_recover_01 \
  --scene C \
  --duration 20 \
  --source realsense \
  --real-robot \
  --auto-y-motion \
  --motion-range 0.20 \
  --motion-omega 0.8 \
  --motion-x-offset -0.05 \
  --record-fps 4 \
  --obstacle-desc "approach hold and leave"
```

## 7. 运行 4.3 主实验

### 7.1 单条序列调试

先用一条动态接近序列检查参考距离和状态条是否合理：

```bash
python -m experiments.exp_43_main \
  --record-dir data/recordings/ch4_3_dynamic_01 \
  --empty-record-dir data/recordings/ch4_3_empty \
  --output data/results/ch4_3 \
  --delta-r 0.05 \
  --bg-eps 0.03 \
  --t-req 0.25 \
  --max-background-points 500000 \
  --danger-threshold 0.10 \
  --plot
```

输出文件：

| 文件 | 内容 |
| --- | --- |
| `data/results/ch4_3/trial_00.json` | 单条 trial 的参考距离、状态序列和各方法指标 |
| `data/results/ch4_3/trial_00_reference.json` | 简化后的 `D_ref(t)` 序列 |
| `data/results/ch4_3/metrics.json` | 多 trial 均值；单条运行时就是该 trial 的均值 |
| `data/results/ch4_3/fig43.png` | 图 4-3 风格距离曲线和状态响应条 |

### 7.2 多条动态接近序列聚合

```bash
python -m experiments.exp_43_main \
  --record-dir data/recordings/ch4_3_dynamic_01 \
  --record-dir data/recordings/ch4_3_dynamic_02 \
  --record-dir data/recordings/ch4_3_dynamic_03 \
  --record-dir data/recordings/ch4_3_dynamic_04 \
  --record-dir data/recordings/ch4_3_dynamic_05 \
  --record-dir data/recordings/ch4_3_dynamic_06 \
  --record-dir data/recordings/ch4_3_dynamic_07 \
  --record-dir data/recordings/ch4_3_dynamic_08 \
  --empty-record-dir data/recordings/ch4_3_empty \
  --output data/results/ch4_3/final_dynamic \
  --delta-r 0.05 \
  --bg-eps 0.03 \
  --t-req 0.25 \
  --max-background-points 500000 \
  --danger-threshold 0.10 \
  --prediction-velocity-radius-scale 0.10 \
  --plot
```

终端会打印表 4-4 格式：

```text
| 方法 | T_lead↑ | R_miss↓ | R_false-time↓ | D_trigger_ref | N_switch↓ |
```

本次最终采用 8 条动态接近序列，`prediction_horizon=0.40 s`、`risk_margin=0.035 m`、`prediction_velocity_radius_scale=0.10`。结果保存到 `data/results/ch4_3/final_dynamic/`，代表性图保存到 `data/results/ch4_3/final_figures/fig43_dynamic.png`。

| 方法 | T_lead↑ | R_miss↓ | R_false-time↓ | D_trigger_ref | N_switch↓ |
| --- | ---: | ---: | ---: | ---: | ---: |
| DSA | 8.3893 | 0.0000 | 1.0000 | inf | 0.0000 |
| SSM | 4.7356 | 0.0000 | 0.2141 | inf | 13.7500 |
| Ours-w/o Temporal | 4.7356 | 0.0000 | 0.2141 | inf | 13.7500 |
| Ours | 5.1286 | 0.0000 | 0.4482 | 0.3551 | 14.2500 |

该结果表明：Ours 相比 SSM 提前约 `0.39 s` 触发，且没有漏警；首次触发时参考距离约 `0.355 m`，说明预测风险占据能在障碍物尚未进入危险区时提前给出预警。代价是 `R_false-time` 较高，反映预测方法更保守。

## 8. 参数说明

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--delta-r` | `0.05 m` | 4.2 Ours 自滤除阈值 |
| `--bg-eps` | `0.03 m` | 空场景背景差分阈值 |
| `--t-req` | `0.25 s` | 最小提前预警需求时间 |
| `--record-fps` | `0` | 录制保存帧率；`0` 表示保存所有相机帧，90 秒实验建议 `4` |
| `--motion-x-offset` | `0.0 m` | 启动 Y 轴往返前的 TCP X 方向偏移；负数表示减小 X |
| `--max-background-points` | `500000` | 空场景背景 KD-tree 最多保留的降采样点数 |
| `--danger-threshold` | `d_stop` | 定义 `t_danger` 的参考距离阈值；动态预警实验建议 `0.10 m` |
| `d_safe` | `config/safety.yaml` 中 `0.15 m` | 安全距离阈值 |
| `d_slow` | `config/safety.yaml` 中 `0.10 m` | 减速阈值 |
| `d_stop` | `config/safety.yaml` 中 `0.05 m` | 停止阈值 |
| `prediction_horizon` | `0.4 s` | Ours 预测时间窗口 |
| `prediction_step` | `0.1 s` | Ours 预测步长 |
| `risk_margin` | `0.035 m` | 动态风险占据基础膨胀余量 |
| `--prediction-velocity-radius-scale` | `config/safety.yaml` | 命令行覆盖动态速度半径膨胀系数；最终实验使用 `0.10` |
| `prediction_static_speed_threshold` | `0.08 m/s` | 低于该速度按静态障碍处理，避免点云中心抖动造成过度预测 |
| `prediction_static_margin` | `0.0 m` | 静态障碍不额外膨胀预测球，动态障碍仍使用 `risk_margin/uncertainty` |

调参建议：

- 若静态场景误警太多，优先检查相机外参、自滤除阈值和桌面平面剔除；
- 若 `D_ref(t)` 长时间为 `inf`，说明参考障碍物未被背景差分保留下来，可适当减小 `bg_eps` 或检查空场景是否与测试场景过于相似；
- 若动态目标速度估计抖动，可调整 `velocity_alpha`、`pos_alpha`、`motion_gate` 和 `min_track_age`。
