## 6.1.1 实验平台

### 1. 小节目标

说明本文实验采用“仿真-回放-虚拟闭环-真实机械臂”融合平台，而不是单一仿真或单一真机验证。该部分应突出不同平台承担不同证据功能：

```text
软件回放：验证感知、自滤除、对象跟踪和时空风险预警；
仿真实验：验证构型风险、NUBS 轨迹优化和方法对比；
虚拟闭环：验证动态障碍、重规划、候选验收和安全接管逻辑；
真实机械臂：验证 RGB-D 感知、真实关节状态、全身风险距离和低速安全运动闭环。
```

### 2. 平台构成

#### 2.1 感知与风险建模平台

需要在论文中列明：

| 项目 | 内容 | 需要记录 |
|---|---|---|
| RGB-D 相机 | Intel RealSense D435i | 型号、分辨率、帧率、深度单位 |
| 安装方式 | 外部固定视角 | 相机到机器人基坐标系外参 |
| 点云输入 | RGB-D 当前帧或录制序列 | 时间戳、点数、深度有效率 |
| 机器人模型 | AUBO i16 URDF/Mesh | URDF 路径、Mesh 版本、采样密度 |
| 机器人状态 | `q`、`qdot`、`qddot` | 来源、频率、时间戳同步方式 |
| 外部障碍表达 | 点云、聚类对象、预测球或体素 | 中心、半径、速度、置信度 |
| 风险输出 | `R_env`、`R_body`、`D_min`、`J_risk` | 最近点、最近连杆、风险等级 |

建议在 6.1 中给出一张系统框图：

```text
RGB-D 点云 + 机器人状态
        ↓
坐标变换与工作空间裁剪
        ↓
机械臂自身点云剔除
        ↓
外部点云聚类、跟踪、速度估计
        ↓
对象级时空风险占据
        ↓
URDF/Mesh 全身风险距离
        ↓
NUBS 轨迹优化或动态安全响应
```

#### 2.2 仿真实验平台

需要说明仿真平台不追求视觉真实，而追求可控、可重复和可统计。

仿真输入：

```text
q_start
q_goal
关节限位、速度限位、加速度限位
静态障碍物位置、尺寸和数量
动态障碍物初始位置、速度、运动模式
NUBS 轨迹分段数、总时间、采样分辨率
随机种子和场景编号
```

仿真输出：

```text
连续轨迹 q(t)
密集采样 D_min(t)
风险积分 J_risk
平滑性代价 J_smooth
目标误差 goal error
限位违规次数
优化耗时和收敛状态
候选轨迹验收结果
```

建议在论文中强调仿真平台承担三项任务：

```text
1. 构造末端安全但身体连杆危险的反例；
2. 在相同障碍场景下比较不同轨迹规划方法；
3. 对障碍速度、数量、间隙、采样密度和权重参数做统计实验。
```

#### 2.3 虚拟闭环平台

虚拟闭环用于连接“离线轨迹优化”和“在线动态执行”。

核心循环：

```text
初始化 q_sim, qd_sim, q_goal, obstacle_state
for each control step:
    更新动态障碍物状态
    根据 q_sim 计算全身风险距离 D_min
    评估当前参考轨迹未来风险
    若风险达到触发条件，启动异步 NUBS 重规划
    若候选轨迹完成，执行 dense 复核和切换状态检查
    高频安全层输出 qd_cmd
    虚拟执行器积分得到下一时刻 q_sim
    记录风险、控制、重规划和状态切换日志
```

需要记录的关键状态：

| 字段 | 含义 |
|---|---|
| `t` | 闭环时间 |
| `q_sim`、`qd_sim` | 虚拟执行状态 |
| `obstacle_state` | 动态障碍物状态 |
| `risk_level` | LOW/MID/HIGH 或等价状态 |
| `D_min` | 当前全身最小距离 |
| `active_plan_id` | 当前执行轨迹编号 |
| `replan_triggered` | 是否触发重规划 |
| `candidate_accepted` | 候选是否通过验收 |
| `candidate_reject_reason` | 拒绝原因 |
| `safety_action` | 正常、减速、排斥、停止 |

#### 2.4 真实机械臂平台

真实平台应采用分阶段、安全闭锁的描述，避免让论文显得直接进行高风险在线切换。

真实平台组成：

| 项目 | 内容 |
|---|---|
| 机械臂 | AUBO i16 |
| 末端执行器 | 大寰夹爪 |
| 相机 | Intel RealSense D435i |
| 相机布置 | 固定外部视角 |
| 标定 | 相机坐标系到机器人基坐标系外参 |
| 控制模式 | 低速关节空间运动、往复运动、影子模式或候选轨迹验证 |
| 障碍物 | 软质障碍物、手持障碍物或带标记物体 |
| 安全措施 | 低速、小范围、急停按钮、人工监控、候选验收、规划超时保护 |

真实实验分三层说明：

```text
A. 影子模式：只记录风险与候选轨迹，不向机械臂下发候选；
B. 安全响应：允许速度缩放、零速停止等安全层动作；
C. 低速候选切换：只有全部安全闸门满足时才允许。
```

6.1 中只定义平台和安全协议。真实结果放在 6.6 和 6.7。

## 6.1.3 对比方法设计

### 1. 小节目标

说明本文不是只展示 CCRO-NUBS 自身结果，而是从感知、风险距离、轨迹规划和动态闭环四个层面设置对比方法。

### 2. 环境占据感知对比

| 方法 | 简称 | 输入 | 输出 | 对比目的 |
|---|---|---|---|---|
| 当前帧点云聚类 | Current Clustering | 当前帧外部点云 | 当前障碍聚类 | 验证无时序预测时动态预警不足 |
| 体素占据 | Voxel Occupancy | 外部点云 | 体素占据集合 | 验证离散占据表达的局限 |
| 八叉树占据地图 | OctoMap | 连续点云帧 | 概率占据地图 | 验证传统地图在动态障碍下的残留问题 |
| 本文对象级时空风险 | Ours-STRO | 聚类、跟踪和速度估计 | 预测风险占据 | 验证提前预警和残留抑制 |

实现步骤：

```text
1. 选择同一组 RGB-D 回放序列；
2. 对每帧执行统一的坐标变换、工作空间裁剪和自滤除；
3. 将同一外部点云送入不同占据方法；
4. 在相同时间戳下计算障碍检测率、保留率、残留率和预警时间；
5. 对动态障碍离开区域后的占据残留进行统计；
6. 输出每种方法的时序曲线、代表帧可视化和汇总表。
```

### 3. 构型风险距离对比

| 方法 | 简称 | 风险作用对象 | 动态预测 | 对比目的 |
|---|---|---|---|---|
| 末端距离 | EEF-only | 末端点或末端球 | 否 | 证明只看末端会漏掉身体连杆风险 |
| 当前帧全身距离 | Body-current | URDF/Mesh 全身表面点 | 否 | 证明全身几何能发现近场连杆风险 |
| 本文构型耦合时空风险 | Ours-CCRO | URDF/Mesh 全身表面点 | 是 | 证明全身与时间预测同时必要 |

典型场景：

```text
场景 A：障碍物靠近末端；
场景 B：障碍物靠近前臂或腕部，末端距离仍安全；
场景 C：多个障碍物分布在末端和身体连杆附近；
场景 D：动态障碍物未来穿越身体连杆区域。
```

### 4. 轨迹规划对比

| 方法 | 简称 | 轨迹表示 | 风险项 | 说明 |
|---|---|---|---|---|
| RRT-Connect + smoothing | RRT-Connect | 采样路径 + 平滑 | 碰撞检测或距离复核 | 经典采样式基线 |
| MINCO-base | MINCO-base | 多项式轨迹 | 无本文风险项 | 最小控制量轨迹基线 |
| MINCO-risk | MINCO-risk | 多项式轨迹 | 同一 `J_risk` | 分离轨迹表示与风险项贡献 |
| NUBS-base | NUBS-base | 非均匀 B 样条 | 无全身时空风险 | 验证仅平滑轨迹不足 |
| 本文方法 | CCRO-NUBS | 非均匀 B 样条 | 构型耦合时空风险 | 完整方法 |

对比时需要固定：

```text
q_start
q_goal
障碍物几何与运动轨迹
关节限位、速度限位、加速度限位
总规划时间预算
轨迹密集采样分辨率
安全阈值 d_safe、d_slow、d_stop
目标到达误差阈值
```

### 5. 动态闭环对比

| 方法 | 简称 | 是否改变轨迹 | 是否重规划 | 主要作用 |
|---|---|---|---|---|
| 距离缩放 | SSM/Scaling | 否 | 否 | 根据风险降低执行速度 |
| 人工势场 | APF | 局部改变速度 | 否 | 通过排斥速度远离障碍 |
| 静态 NUBS | Static NUBS | 初始轨迹固定 | 否 | 验证单次规划无法适应动态变化 |
| 本文动态重规划 | CCRO-NUBS Replanning | 是 | 是 | 验证风险触发局部重规划和候选验收 |
| 完整执行层 | Ours-Full | 是 | 是 | 重规划 + 高频安全层兜底 |

## 6.1.4 公平性协议

### 1. 小节目标

建立所有后续对比实验必须遵守的统一规则，避免不同方法使用不同输入、不同采样或不同验收标准。

### 2. 统一输入规则

所有同组实验必须保持：

```text
1. 相同起始构型 q_start；
2. 相同目标构型 q_goal；
3. 相同障碍物初始状态、尺寸、速度和轨迹；
4. 相同机器人 URDF/Mesh 模型；
5. 相同关节位置、速度和加速度限制；
6. 相同安全距离阈值 d_safe、d_slow、d_stop；
7. 相同随机种子集合；
8. 相同最大规划时间；
9. 相同优化终止条件；
10. 相同 dense 复核采样分辨率。
```

### 3. 统一验收规则

一次轨迹规划成功需要同时满足：

```text
goal error <= epsilon_goal
min_t D_min(q(t), t) >= d_stop
关节位置不超限
关节速度不超限
关节加速度不超限
优化或规划未超过时间预算
dense 复核通过
```

动态闭环成功需要同时满足：

```text
最终到达目标或进入允许目标邻域
执行期间没有 D_min < d_stop 的危险侵入
T_viol 在允许范围内，最好为 0
出现 HIGH 风险、优化超时或候选拒绝时能够安全停止
控制循环未被规划器阻塞
所有候选切换满足边界连续性和安全复核
```

### 4. 随机实验与统计规则

建议设置三类统计粒度：

```text
调试级：每类场景 3-5 个随机种子，用于开发检查；
论文级：每类关键场景 20-30 个随机种子；
压力级：障碍速度、数量、间隙、噪声等参数扫描。
```

所有随机方法应报告：

```text
mean
standard deviation
median
p95
max
success rate
timeout rate
candidate rejection rate
```

### 5. 版本与日志规则

每次实验必须保存：

```text
Git commit
实验配置 yaml/json
随机种子
机器信息
Python 和关键依赖版本
输入数据路径或数据哈希
输出 metrics.json
失败样本日志
代表性可视化图
```

建议所有后续实验目录统一包含：

```text
manifest.json
config.yaml
metrics.json
trials.csv
failures.jsonl
figures/
logs/
```
