## 6.2 小节定位

6.2 用于证明第六章证据链的输入端可靠，即：

```text
1. RGB-D 点云经过坐标变换、自滤除和聚类后，可以保留外部障碍物；
2. 外部障碍物能够形成对象级表达，包括中心、尺寸、速度和置信度；
3. 对象级时空风险占据能够比当前帧静态距离更早响应动态障碍；
4. 动态障碍离开后，本文对象级方法能够减少传统占据地图的残留问题；
5. 真实 RGB-D 数据下，外部占据解耦和对象级风险建模流程具备可用性。
```

本节建议分成两个主要实验：

```text
6.2.1 仿真/回放环境占据对比实验
6.2.2 真实 RGB-D 外部占据解耦与对象级风险建模实验
```

其中 6.2.1 可以立即运行程序生成结果；6.2.2 先按真实实验步骤采集数据，后续再补真实结果表格。

## 6.2.1 仿真/回放环境占据对比实验

### 1. 实验目的

验证不同环境占据表达在静态障碍、动态接近、动态穿越和障碍离开场景下的表现差异。

需要回答的问题：

```text
Q1：只使用当前帧点云聚类能否稳定检测外部障碍物？
Q2：体素占据和 OctoMap 类地图是否会引入动态障碍残留？
Q3：对象级时空风险能否相对当前帧方法提前预警？
Q4：对象级方法是否能够在动态障碍离开后更快恢复 SAFE？
Q5：不同方法的检测率、保留率、残留率和耗时差异如何？
```

### 2. 对比方法

| 方法 | 程序名称 | 输入 | 输出 | 论文用途 |
|---|---|---|---|---|
| 当前帧点云聚类 | `current_clustering` | 当前帧外部点云 | 聚类后的当前障碍点云 | 验证无预测的当前帧基线 |
| 体素占据 | `voxel_occupancy` | 当前帧外部点云 | 当前体素中心 | 验证离散占据表达 |
| OctoMap 类衰减占据 | `octomap_decay` | 连续帧外部点云 | 带时间衰减的体素记忆 | 验证动态场景残留问题 |
| 本文对象级时空风险 | `ours_stro` | 聚类、跟踪、速度估计 | 预测风险球和对象占据 | 验证提前预警能力 |

说明：

```text
STRO = Spatio-Temporal Risk Occupancy。
本程序中的 OctoMap-like 是轻量级概率/记忆占据近似，用于复现传统地图保留历史占据的核心行为，不声称等同于完整 OctoMap 官方实现。
```

### 3. 仿真场景

程序内置四类场景：

| 场景 | 程序名称 | 作用 | 主要指标 |
|---|---|---|---|
| 静态安全障碍 | `static_safe` | 检查无危险接近时的误警率 | `R_false_time` |
| 动态接近 | `approach` | 障碍物从远处接近机械臂 | `T_lead`、`R_miss` |
| 动态穿越 | `crossing` | 障碍物未来穿越机器人邻域 | `T_lead`、`R_miss` |
| 靠近后离开 | `leave` | 障碍物离开后检查占据残留 | `R_ghost`、`R_false_time` |

仿真数据包含：

```text
简化机器人表面点云；
外部球形障碍物点云；
背景噪声点；
动态障碍物真实中心、半径和速度；
每帧真实障碍物到机器人表面的距离 d_true(t)。
```

### 7. 评价指标

| 指标 | 含义 | 趋势 |
|---|---|---|
| `R_det` | 外部障碍物检测率 | 越高越好 |
| `R_keep` | 外部障碍物点云保留率 | 越高越好 |
| `R_over` | 非障碍点/过保留占据比例 | 越低越好 |
| `R_ghost` | 障碍物离开后的残留占据率 | 越低越好 |
| `T_lead` | 提前预警时间 | 越高越好，但需结合误警率 |
| `R_miss` | 漏报率 | 越低越好 |
| `R_false_time` | 误报时间占比 | 越低越好 |
| `T_process_ms_mean` | 单帧平均处理耗时 | 越低越好 |
| `T_process_ms_p95` | 单帧 p95 处理耗时 | 越低越好 |

## 6.2.2 真实 RGB-D 外部占据解耦与对象级风险建模实验

### 1. 实验目的

在真实 RealSense 点云和 AUBO i16 机械臂状态下验证：

```text
1. 外部点云能从机器人自身点云中解耦出来；
2. 静态障碍物能被稳定保留和检测；
3. 动态障碍物能被聚类、跟踪和估计速度；
4. 对象级风险能生成提前预警；
5. 障碍物离开后系统能恢复 SAFE；
6. 整个感知与风险建模链路耗时可记录。
```

### 2. 实验边界

本节真实实验只验证感知和风险建模，不要求真实机械臂执行 NUBS 在线重规划。

允许：

```text
真实 RGB-D 采集；
真实机械臂低速参考运动；
离线回放评估；
影子模式风险预警；
记录候选风险状态。
```

不允许：

```text
根据本节实验结果直接向机械臂下发新轨迹；
绕过 P7 安全闸门进行候选切换；
用评价真值区域参与在线检测或风险判断。
```

### 8. 场景 D：靠近-停留-远离

### 11. 真实实验验收标准

```text

3. 动态接近场景中 Ours 的 T_lead 大于当前帧方法；
4. 靠近-远离场景中 Ours 能恢复 SAFE；
5. 所有 trial 有完整 timestamp、joint_values 和 points_cam；
6. 所有真实结果可以追溯到 record_dir、config 和 git commit。
```

如果真实动态序列缺少中心真值，则论文中应明确：

```text
D_ref(t) 为基于空场景差分和机器人表面距离构造的离线弱真值；
该真值只用于评价，不参与在线风险判断。
```
