## 6.8.2 可以直接写入论文的结论

建议正文表述：

```text
1. 对象级时空风险占据在仿真和真实回放中均能提供动态障碍预警；
2. 构型耦合全身风险距离能够识别仅末端距离遗漏的身体连杆风险；
3. 风险约束 CCRO-NUBS 在静态风险场景中能够通过 dense Mesh 安全复核；
4. 与 MINCO-risk、RRT-Connect+smoothing 等关节空间复现基线相比，CCRO-NUBS 在安全约束和连续轨迹优化接口上更统一；
5. 虚拟闭环中，风险触发重规划可提升动态障碍场景下的最小距离；
6. 消融实验表明，时序预测、全身风险、排斥向量和安全滤波均有独立贡献；
7. 当前软件安全门控可以 fail-closed，未满足实机条件时不会允许低速轨迹切换。
```

## 6.8.3 需要保守表述的结论

以下内容不能过度宣称：

```text
1. 不能写“已完成真实机械臂在线 NUBS 轨迹切换闭环”；
   当前 P7 结果为 dry-run / shadow 允许，low_speed_switch 禁止。

2. 不能写“MINCO 官方工程已完整部署在机械臂任务中”；
   当前为参照 GCOPTER/MINCO 思想的关节空间复现基线。

3. 不能把 4.6/ch6_7 的分模块计时写成完整真实端到端计时；
   当前真实回放日志缺少 RGB-D 预处理、聚类、跟踪、预测等非零计时。

4. 不能只用 jerk 或耗时评价外部规划器；
   必须同时报告 dense D_min、goal error、限位违规和候选验收。
```

## 6.8.4 方法局限

表格：

```text
data/results/ch6_8/limitations.md
```

正文可写：

```text
1. 当前动态障碍预测采用短时匀速模型，对复杂非线性运动仍有局限；
2. Mesh 表面点云距离计算在高采样密度下耗时较高；
3. NUBS 在线重规划适合触发式低频执行，而不是每帧高频优化；
4. 真实实验中深度噪声、遮挡和外参误差可能导致风险估计保守；
5. 真实在线轨迹切换仍需通过 watchdog、通信、时间戳、急停和厂家限位检查；
6. 外部基线当前为机械臂关节空间复现版本，严格官方工程对比可作为后续补充。
```
